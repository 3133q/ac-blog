# 注意点合集

## 一

关于前缀和问题，有些题如果要求***之后，让某个值最大，如果能跟前缀和联系上，一般来说，只要前缀和大于0，就可以累加（算上），不需要说前缀和大于上一个数这样的，没必要想太多

### 例题：

[P6625 [省选联考 2020 B 卷\] 卡牌游戏 - 洛谷](https://www.luogu.com.cn/problem/P6625?contestId=312843)

### 代码：

```c++
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll ans,x,s,n;
int main() {
	cin>>n;
	for (ll i=1; i<=n; i++) {
		cin>>x;
		s+=x;
		if (s>0&&i!=1) 
			ans+=s;
	}
	cout<<ans;
	return 0;
}
```
