# 血泪史一

## 题目

[B-Card Game_2026牛客寒假算法基础集训营1](https://ac.nowcoder.com/acm/contest/120561/B)

### 描述

![image-20260204153327634](/images/image-20260204153327634.png)

题目虽说很冗杂，但仔细想想，画画，会发现其实就是道简单的数学题，具体应该不用我说咋推理出来的，毕竟这个笔记是血泪史。。。。

简单说说思路吧，就是第二个人找出他的牌的最小值，然后看看第一个人有多少张比他最小值还更小的，累计起来，然后分两部分，进行排列组合（例如一个n 一个m），即为

#### 公式

$$
A_{n}^{n}\times A_{m}^{m}=n!\times m!
$$

##### 问题所在

取模部分出现问题。。。

#### AC代码

```c++
#include<bits/stdc++.h>
using namespace std;
const int N=998244353;
int a[200001],b[200001];
int t,n,minn,s=0,s1=0;
long long ans=1,ans1=1;
void solve(){
    for(int i=1;i<=s;i++){
        ans*=i%N;
        ans%=N;
    }
    for(int i=1;i<=s1;i++){
        ans1*=i%N;
        ans1%=N;
    }
    ans1=ans%N*ans1%N;
}
int main(){
    std::cin>>t;
    for(int i=0;i<t;i++){
        ans=1,ans1=1,s=0,s1=0;
        std::cin>>n;
        for(int j=0;j<n;j++) std::cin>>a[j];
        for(int j=0;j<n;j++) std::cin>>b[j];
        minn=*min_element(b,b+n);
        for(int j=0;j<n;j++){
            if(a[j]<minn) s++;
        }
        s1=n-s;
        solve();
        std::cout<<ans1<<'\n';
    }
    return 0;
}
```

对比发现，只有括号问题，就是(ans%N)*(ans1%N) 和 ans%N * ans1%N   的区别

害，这问题还真挺大。。。

##### AI解释

> `ans1 = ans % N * ans1 % N;`在语法解析时，按 C 语言优先级规则：
>
> - 
>
>   `%`和 `*`优先级相同，左结合。
>
> - 
>
>   所以它等于：
>
>   `ans1 = ((ans % N) * ans1) % N;`
>
> 注意这里 `ans1`是**右边的旧值**，然后整个结果再赋给左边的 `ans1`。
>
> ------
>
> `ans1 = (ans % N) * (ans1 % N);`等于：
>
> - 
>
>   先分别对 `ans`和 `ans1`取模 N，
>
> - 
>
>   相乘，
>
> - 
>
>   然后**没有再次取模 N**，结果可能大于 N。

举例说明

> N = 10
> ans = 12
> ans1 = 7
> 第一种写法：
>
> ans1 = ans % N * ans1 % N
>
> → ans % N= 2
>
> → 2 * ans1= 2 * 7 = 14
>
> → 14 % N= 4
>
> 结果 ans1 变成 4。
>
> 第二种写法：
>
> ans1 = (ans % N) * (ans1 % N)
>
> → ans % N= 2
>
> → ans1 % N= 7
>
> → 相乘 = 14
>
> 结果 ans1 变成 14（没有对 14 再取模 N）。

#### 正确且高效稳定的写法

> ans1 = 1LL * (ans % N) * (ans1 % N) % N;
>
> 也可以只写 ans*ans1%N
>
> 或者 1LL* ans * ans1 %N
