最大连续子序列和问题

若给出一系列数，要求出该数组里面连续子数组的和的最大值，很容易想到用动态规划的思路去求解，但对于这种问题，可以使用前缀和思路和动态规划的思路去求解

例如，给出 -2 1 -3 4 -1 2 1 -5 4

前缀和算法使用的优势在于：可以快速算出某一区间的和，即 sum[j]-sum[i-1]，所以说，明白这个可以开始解题了，先对每一位的前缀和进行计算，计算一个数组所有元素之和，然后从左往右去遍历（对于这种求最值的问题，一定记得循环每次都要更新最值），只要左边的前缀和最小，那么右边的一定最大，但是注意，最小的可能不是从第一个元素开始，所以要更新最小值

具体代码如下：

```c++
// 返回给定整数数组的最大连续子序列的和。
int LargestSumContiguousSubarray(int nums[], int length) {
    // Sum of 1..j
    int sum = 0;
    // Min value of sum(i), where i < j.
    int min = 0;
    // Max value of delta, where delta = sum(j) - min.
    int max = nums[0];

    for (int j = 0; j < length; j++) {
        sum += nums[j];
        int delta = sum - min;
        if (delta > max) max = delta;
        if (sum < min) min = sum;
    }
    return max;
}
```

这题的DP需要套点传统思路，不然刚开始没想法 qwq

由于考虑舍弃掉某个数作为开头的条件是当累加后出现负数的情况，所以在遍历中可以用前推后，也就是使用

dp[i-1]去判断，若这个值是负数的话，直接舍掉，从下一个数开始重算，如果为正值的话，直接累加就好了

```c++
// 返回给定整数数组的最大连续子序列的和。
int LargestSumContiguousSubarray(int nums[], int length) {
    if (length <= 0) return 0;

    int max = 0;
    int dp[length];
    dp[0] = nums[0];

    for (int i = 1; i < length; i++) {
        if (dp[i - 1] > 0)
            dp[i] = dp[i - 1] + nums[i];
        else
            dp[i] = nums[i];

        if (max < dp[i]) max = dp[i];
    }
    return max;
}
```



例题：[P1115 最大子段和 - 洛谷](https://www.luogu.com.cn/problem/P1115)

代码：

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
using namespace std;
const int N=1e6+2;
int dp[N],n,a[N];
int main(){
	std::cin>>n;
	for(int i=1;i<=n;i++) std::cin>>a[i];
	int ans=-1e8;
	for(int i=1;i<=n;i++){
		if(dp[i-1]<=0) dp[i-1]=0;
		dp[i]=max(dp[i-1]+a[i],a[i]);
		ans=max(ans,dp[i]);
	}
	std::cout<<ans;
	return 0;
}
```
