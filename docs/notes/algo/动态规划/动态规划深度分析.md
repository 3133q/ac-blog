## 简介

动态规划到底是啥？如果用官方的解释

动态规划（Dynamic Programming，简称 DP）是一种解决复杂问题的算法设计方法，其核心思想是将原问题拆解成相对简单的子问题，逐个解决并保存子问题的结果，避免重复计算，从而高效地求解问题。

> 动态规划适合具有以下两个性质的问题：
>
> 1. **重叠子问题**（Overlapping Subproblems）：子问题会重复出现；
> 2. **最优子结构**（Optimal Substructure）：原问题的最优解包含子问题的最优解。

简单理解就是“记住求过的解，避免重复计算”，比如经典的斐波那契数列就是动态规划的入门例子。

但如果要用我自己的话总结，可以这么理解：

**当一个问题不能直接模拟一步步解决的话，而是依赖于这期间所进行的操作，和做出的选择，然后计算最终所得的最优结果（最小or最大），这样的话，就可以概括为选或者不选的结果，而对于选或者不选所对应的步骤中的结果，我们可以直接递推记录，然后一步步往后推，因为采用for循环递推时，我们可以很轻松地把前面所有状态决定之后所带来的最优解，遍历到后面，然后一步步计算**

### 校赛

#### 一 约数之和

题目大致意思：给出一个数S（S&lt;=1000)，要我们选出若干个数和不超过S的前提下，它们的所有约数（不包括它本身）之和达到最大

例如：11

 选择4和6   约数之和为 1+2 + 1+2+3=9

##### 分析

题目其实很明显，选择若干个数，你可以先推一推，可以发现前几个数的约数，或者说所有数的约数，你肯定无法整出啥公式能计算出的吧，也没有啥固定的选择方法，那么就说明，最终的结果取决于你中间过程选择的一些数字，而且还得不超过S就行，妥妥的状态转移嘛！！！

接下来我们一步步来理解如何推导

首先，从小的开始，对于1，没得分，结果为1

2的话，可以拿出约数1    3也一样，只能拿出1   ...............

我们可以先注意一下S的范围，小于等于1000，很小，随你用O(n^2)的复杂度，那是否可以这样呢，我从2开始（因为1结果是0，用1去凑没有意义），对于每一个i，我再开一重for，这里的j目的在于尝试凑，也就是比如说从2开始，j从0开始到正好S-i-1（这里也是剪枝，因为正好为S也没必要），然后使用i+j不断转移状态，最后得出结果

##### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<vector>
#include<cmath>
#include<map>
#include<climits>
#define int long long
using namespace std;
int re(int n){
	if(n==1) return 0;
	if(n==2||n==3) return 1;
	int ans=0;
	for(int i=1;i<=n/2;i++){
		if(n%i==0) ans+=i;
	}
	return ans;
}
signed main(){
	int s,ans=-1e18;
	std::cin>>s;  
	int dp[5001];
	dp[1]=0;
	for(int i=2;i<=s;i++){
		for(int j=0;j<s-i;j++){
			dp[i+j]=max(dp[i+j],dp[j]+re(i));
			ans=max(ans,dp[i+j]);
		}
	}
	std::cout<<ans;
	return 0;
}
```

> 核心思想就是那个状态转移，可以类比为凑数，你无需考虑我11往前一位10他可能由多个数字才能推出来，因为我从2开始试的，通过j去转移，也就是拿出一个2去跟他凑的结果，一直遍历到S-1，然后到3，再到4,....这样如果对于6，我就可以考虑到选了2的情况下，能不能再选个3，然后使最终的结果更大，无形之中已经考虑到了多个数的情况，所以对于dp，不要想太多多个数，或者上一个状态咋推出来的，只要你从一个标准开始枚举，把后面的情况全部都过一遍，这样就可以很轻松的把状态不断更新，得到最优解。

##### 拓展

其实这道题也是一道01背包模型，你只要考虑要不要选择这个数来凑出你最终的结果就好了，所以说直接背包模型转移也行，但是要注意01背包和完全背包的区别，下面会详细讲，这里一个数只能用一次，所以我们推应该得从大往小推



#### 二 好感度

大概意思：给出两组数据，一组A的好感值，一组B的好感值，给出S，要求计算在他们的好感值之和不超过S的条件下，他们的好感值之差最大能达到多少？

##### 分析

这道题其实相对简单，你只需要静下心来好好想想，当然你也得明白动态规划底层逻辑，你就能像我刚刚一样，只需略微出手，就解决了。。

这题本质上和上面一题一样，背包思路，不就在于我现在选不选它来构成我的最终最优答案嘛，如果选了，我推一下他所能构成的所有好感值之和的结果（也就是选他），注意，这里仍然是01背包，因为只能选择一次，然后一步步推就行

##### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<vector>
#include<cmath>
#include<map>
#include<climits>
#define int long long
using namespace std;
signed main(){
	int n,s,ans=-1e18;
	std::cin>>n>>s;
	vector<int>a(n+1),b(n+1),dp(s+1,0);
	for(int i=1;i<=n;i++) std::cin>>a[i]>>b[i];
	for(int i=1;i<=n;i++){
		int c=a[i]+b[i];
		if(c>s) continue;
		for(int j=s;j>=c;j--){
			dp[j]=max(dp[j],dp[j-c]+abs(a[i]-b[i]));
			ans=max(ans,dp[j]);
		}
	}
	std::cout<<ans;
	return 0;
}
```

> 因为最后不一定结果正好凑出来S，所以我们需要中间记录一个最大值，更新他

### 其他

##### 一 LIS

要求一个序列的最长上升子序列，也就是说从一个序列中挑选出一些数字，满足上升的性质，然后要求出最长的长度为多少

举几个例子就可以清楚地知道，本质上就是要考虑谁可以胜任当前的序列位置，并且最终更有潜力让更多数字填进来，所以我们需要动态规划转移状态，一步步考虑如果选了当前状态，是否能让最终结果更大，可以的话就选，不行的话就不更新，也就是核心的选与不选问题

朴素的算法（O(n^2)）

```c++
#include<iostream>
#include<vector>
#include<map>
#include<algorithm>
#include<cmath>
#include<climits>
#define int long long
using namespace std;
signed main() {
	int n,ans=-1e18;
	std::cin>>n;
	vector<int>a(n+1),dp(n+1,1);
	for(int i=1;i<=n;i++) std::cin>>a[i];
	for(int i=1;i<=n;i++){
		for(int j=1;j<i;j++){
			if(a[i]>a[j]) dp[i]=max(dp[i],dp[j]+1);
			ans=max(ans,dp[i]);
		}
	}
	std::cout<<ans;
	return 0;
}
```

> 分析可知，就是相当于设定当前位置i，为最终的末位置，然后从前往后去推状态，一步一步解，算出最后的结果，但有了这样的想法，我们或许可以优化一下

```c++
#include<iostream>
#include<vector>
#include<map>
#include<algorithm>
#include<cmath>
#include<climits>
#define int long long
using namespace std;
int dp[100001];
signed main() {
	int n,ans=-1e18;
	std::cin>>n;
	vector<int>a(n+1);
	for(int i=1;i<=n;i++) std::cin>>a[i];
	int len=0;
	for(int i=1;i<=n;i++){
		if(a[i]>dp[len]){
			dp[++len]=a[i];
		}
		else *lower_bound(dp+1,dp+1+len,a[i])=a[i];
	}
	std::cout<<len;
	return 0;
}
```

其实思路很简单，就是用了个二分查找函数，如果当前数正好大于dp数组里的最后一个数，那么直接添加到末尾，没有问题，但如果出现了在数组里的数字中间的值，那么就把他放在数组里第一个大于等于该数的位置，这样他的所在位置正是能更好贡献的地方，以此让最后的长度更大

##### 二 LCS

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<vector>
#include<algorithm>
#include<map>
#include<climits>
using namespace std;
signed main(){
	string s,t;
	std::cin>>s>>t;
	int l1=s.size();
	int l2=t.size();
	//int l=max(l1,l2);
	int dp[500][500];
	for(int i=1;i<=l1;i++){
		for(int j=1;j<=l2;j++){
			if(s[i-1]==t[j-1]) dp[i][j]=dp[i-1][j-1]+1;
			else dp[i][j]=max(dp[i-1][j],dp[i][j-1]); 
		}
	}
	std::cout<<dp[l1][l2]<<'\n';
	string a;
	int i=l1,j=l2;
	while(i>0&&j>0){
		if(s[i-1]==t[j-1]) {
			a+=s[i-1];
			i--;
			j--;
		}
		else if(dp[i-1][j]>dp[i][j-1]) i--;
		else j--;
	}
	reverse(a.begin(),a.end());
	std::cout<<a;
	return 0;
}
```

前半段是常规的LCS模板，核心在于从上一步转移，如果s[i-1]==t[j-1]也就代表着当前位置的上一步两个字符是匹配的，那么直接递推，当前长度加一即可，否则，使用递推思路，分别向两个字符串缩一个长度，看看往哪缩当前匹配上的长度更大，直接选大的即可

后半段是拓展部分，利用倒推法去还原已经匹配的字符串，思路是从后往前，如果找到一样的字符，则肯定是LCS的一部分，直接累加，不然的话，看看是从哪里转移过来的，往大的地方去递减，然后不断寻找当时选定的字符

###### 分析

先把他当做一道数学题处理，每抛出一次硬币，出现正面的概率和反面的概率分别为pi和1-pi，求抛出N枚硬币之后正面比反面多的概率

也就是可以转化为正面次数至少为N/2+1次，将其概率算出来，这里可以采用概率dp的思想，也就是转移状态，标定dp[i] [j]表示当第i次抛完之后，总共出现j次正面的概率，然后计算时
$$
dp[i][j]=dp[i-1][j]\times(1-p[i])+dp[i-1][j-1]\times p[i]
$$
注意边界，需要满足j&gt;0，否则只能算前半段

最后直接累加
$$
ans=\sum_{j=N/2+1}^{N}dp[N][j]
$$
就是最后的答案

###### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<cmath>
#include<vector>
#include<algorithm>
#include<map>
#include<climits>
#include<iomanip>
#define ing long long
using namespace std;
signed main(){
	int n;
	std::cin>>n;
	vector<double>p(n+1);
	for(int i=1;i<=n;i++) std::cin>>p[i];
	vector<vector<double>>dp(n+1,vector<double>(n+1,0));
	dp[0][0]=1.0;
	for(int i=1;i<=n;i++){
		for(int j=0;j<=i;j++){
			dp[i][j]+=dp[i-1][j]*(1.0-p[i]);
			if(j>0) dp[i][j]+=dp[i-1][j-1]*p[i];
		}
	}
	double ans=0;
	for(int j=n/2+1;j<=n;j++) ans+=dp[n][j];
	std::cout<<fixed<<setprecision(10)<<ans;
	return 0;
}
```
