# 动态规划实例

## 例题一

[P8784 [蓝桥杯 2022 省 B\] 积木画 - 洛谷](https://www.luogu.com.cn/problem/P8784)

### 题目大意

<img src="/images/image-20260309193024948.png" alt="image-20260309193024948" style="zoom:80%;" />

本质上就是给出2*N的一个矩形，要求用I型积木或者L型积木去把它填满，问有多少种方式？

### 分析

看到这种问题，很容易想到要递推，用上动态规划，但是该如何推导呢？

其实dp的本质在于找到状态转移，得知道如何从上一个状态推到下一个，可以是当前的最大价值，当前的容量，.....，但在这一题，我们可以定义为当前填满的方案数，对于dp，一定要跳脱出一种惯性思维，就是认为我一定得前面的几个过程明白得清清楚楚，或者说按照数学那样直接一步步往后推，不是！！！对于dp，核心就在于假设前面的情况我们已经处理好了，只需要利用前一个状态去推下一个即可，至于上一个状态共有几种，不一定要明确，比如那这题做分析吧

假设dp[i]表示2*i的矩形填满的方案数，那么

对于i-1的时候，这时就可以当做2*(i-1)的矩形已经填满了，方案数已经在dp[i-1]中了，现在还差最后一列，而我们别无选择，只能放一个竖的方块，也就是前面的方案数直接加过来就行

对于i-2，同样，这时因为已经加上了i-1的情况（不能重复），所以新的情况只有两个I型的积木横着放，这样的话，也可以直接从前面的方案数推过来

对于i-3，这种有些不太一样，因为这样可以放L型的积木了，而很容易可以发现L型积木摆放时会有两种方法，相对称的情况，所以前面的方案数推过来要乘2
$$
dp[i]=dp[i-1]+dp[i-2]+2\times dp[i-3]+.... 2\times dp[1]
$$
然后写个dp[i-1]
$$
dp[i-1]=dp[i-2]+dp[i-3]+2\times dp[i-4]+.... 2\times dp[1]
$$
两式相减
$$
dp[i]=2\times dp[i-1]+dp[i-3]
$$

### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
using namespace std;
using ll=long long;
const int N=1e7+2;
const long long mod=1e9+7;
ll n,dp[N];
int main(){
	std::cin>>n;
	dp[1]=1;
	dp[2]=2;
	dp[3]=5;
	if(n<4){
		std::cout<<dp[n]%mod;
		return 0;
	}
	for(int i=4;i<=n;i++) dp[i]=((2*dp[i-1]+dp[i-3])+mod)%mod;
	std::cout<<dp[n]%mod;
	return 0;
}
```

## 例题二

[P2347 [NOIP 1996 提高组\] 砝码称重 - 洛谷](https://www.luogu.com.cn/problem/P2347)

### 题目大意

<img src="/images/image-20260314113605291.png" alt="image-20260314113605291" style="zoom:80%;" />

### 分析

这道题不能像一般的dp转移题去解，因为他问的是能表示多少种重量，也就是相关状态数的问题，而对于基本的背包问题（以及变式），一般都是问凑出w的金额总共有多少种方式，这样才可以基本地使用+1去转移，而这道题应该使用的是01标记

### 方法一

使用bitset，详细 [bitset](/notes/algo/杂项/bitset) 

将凑成的重量看做是第几位是1，由此状态压缩

#### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
#include<bitset>
using namespace std;
const int N=1e3+8;
int a[7],ans=0;
bitset<N>dp;
int main(){
	dp.reset();
	for(int i=0;i<6;i++) std::cin>>a[i];
	dp[0]=1;
	int v[6]={1,2,3,5,10,20};
	for(int i=0;i<6;i++){
		for(int k=1;k<=a[i];k++){
			for(int j=1000;j>=0;j--){
				dp[j+v[i]]=dp[j];
			}
		}
	}
	dp[0]=0;
	std::cout<<"Total="<<dp.count();
	return 0;
}
```

0的位置赋值1，从最大重量枚举，如果在范围内就赋值，最后看有几个1，要注意了，for循环的0问题，因为你的v数组是直接赋值，也就是从0开始，所以说你如果从1开始输入，就会<img src="/images/image-20260314154156429.png" alt="image-20260314154156429" style="zoom:50%;" />

### 方法二

常用妙招，对于这种单纯推状态的题目，可以使用或|，因为0|1=1|0=1|1=1，而0|0=0，以此推1的个数

```c++
#include<bits/stdc++.h>
using namespace std;

const int N=1010;
int a1,a2,a3,a4,a5,a6;
bool dp[N];

int main(){
    scanf("%d%d%d%d%d%d",&a1,&a2,&a3,&a4,&a5,&a6);
    int s=a1+2*a2+3*a3+5*a4+10*a5+20*a6;
    dp[0]=1;
    for (int i=1;i<=a1;++i){
        for (int j=s;j>=i;--j) dp[j]|=dp[j-i];
    }
    for (int i=1;i<=a2;++i){
        for (int j=s;j>=2*i;--j) dp[j]|=dp[j-2*i];
    }
    for (int i=1;i<=a3;++i){
        for (int j=s;j>=3*i;--j) dp[j]|=dp[j-3*i];
    }
    for (int i=1;i<=a4;++i){
        for (int j=s;j>=5*i;--j) dp[j]|=dp[j-5*i];
    }
    for (int i=1;i<=a5;++i){
        for (int j=s;j>=10*i;--j) dp[j]|=dp[j-10*i];
    }
    for (int i=1;i<=a6;++i){
        for (int j=s;j>=20*i;--j) dp[j]|=dp[j-20*i];
    }
    int cnt=0;
    for (int i=1;i<=s;++i){
        if (dp[i]) ++cnt; 
    }
    printf("Total=%d",cnt);
    return 0;
}
```

## 例题三

### 题目大意

<img src="/images/image-20260319182737885.png" alt="image-20260319182737885" style="zoom:80%;" />

### 分析

其实就是最大子段和问题，要我们求出一个序列中最大的子段和（注意是连续），这里要注意，使一段连续的子段和最大，不一定非得选中的区间所有数都大于0，而是要动态考虑，只要目前我累加到的前缀和不会小于等于0，其实也就可以继续往后推，反之，归零，从下一位继续

### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
using namespace std;
const int N=1e6+2;
int dp[N],n,a[N];
int main(){
	std::cin>>n;
	for(int i=1;i<=n;i++) std::cin>>a[i];
	int ans=-1e8;
	for(int i=1;i<=n;i++){
		if(dp[i-1]<=0) dp[i-1]=0;
		dp[i]=max(dp[i-1]+a[i],a[i]);
		ans=max(ans,dp[i]);
	}
	std::cout<<ans;
	return 0;
}
```
