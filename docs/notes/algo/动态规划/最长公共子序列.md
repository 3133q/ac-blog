最长公共子序列

动态规划中最经典的问题，kmp算法实现的是字符串匹配问题，而这个算法，实现求解两个序列最长公共部分的功能，也称为LCS

我们用s代表序列，用s(c)表示序列去掉最后一个元素后的子序列，LCS(s1,s2)表示s1 s2的最长公共子序列长度，现在我们假设s1=abecbab，s2=bdcbabb，现在我们开始匹配

从最后一个元素倒推，如果最后一个元素相同，b=b，则他们的LCS长度就是abecba 和 bdcbab的LCS长度加上1，这个很好理解吧，前面的序列已经是匹配好了的，最后一个元素相同，那就加1嘛

如果最后一个元素不相同，则LCS长度应该为max(LCS(s1(c),s2)，LCS(s1,s2(c))) 也就是两个序列分别去掉最后一个元素，再去看看谁之前能匹配到的最长公共子序列长度更长，注意，如果去掉最后一个元素发现长度为0了，但很明显，返回0

这就是递归判断式

[Problem - 1159](https://acm.hdu.edu.cn/showproblem.php?pid=1159)

模板题，给出代码：

```c++
#include <algorithm>
#include <cstring>
#include <iostream>
using namespace std;
const int MAXN = 505;
char s1[MAXN], s2[MAXN];
int dp[MAXN][MAXN];
int lcs(int n1, int n2)
{
    if (dp[n1][n2] != -1)
        return dp[n1][n2];
    if (n1 == 0 || n2 == 0)
        dp[n1][n2] = 0;
    else if (s1[n1 - 1] == s2[n2 - 1])
        dp[n1][n2] = lcs(n1 - 1, n2 - 1) + 1;
    else
        dp[n1][n2] = max(lcs(n1, n2 - 1), lcs(n1 - 1, n2));
    return dp[n1][n2];
}
int main()
{
    while (cin >> s1 >> s2)
    {
        memset(dp, -1, sizeof(dp));
        cout << lcs(strlen(s1), strlen(s2)) << endl;
    }
    return 0;
}
```

其实递归本质上就是倒推，而相反，递推就是正推即为动态规划

但是注意，对于DP题，一定想清楚了推到最后的那个值，到底是不是我们要的最值，这题是可以的，因为得推完才知道后面能不能再判断了

给出代码：

```c++
while (cin >> s1 >> s2)
{
    memset(dp, 0, sizeof(dp));
    int n1 = strlen(s1), n2 = strlen(s2);
    for (int i = 1; i <= n1; ++i)
        for (int j = 1; j <= n2; ++j)
            if (s1[i - 1] == s2[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
    cout << dp[n1][n2] << endl;
}
```

对于这个状态转移方程式还有一个图形化理解

<img src="https://picx.zhimg.com/v2-eca7fdfbc95c09c7c9a9b1d9084e5f49_1440w.jpg" alt="img" style="zoom:67%;" />

得到这个二维数组后，如果某个dp[i] [j]比他左上方的值大1，且s1[i-1]=s2[j-1]，说明这个元素可以用来增大LCS，于是我们可以采取这样的策略，从右下角开始，如果有dp[i] [j]=dp[i-1] [j-1]+1 则往左上走一格，但如果同时还有s1[i-1]=s2[j-1]，则将其加入，否则的话，他的左边或上边至少有一个跟他相等，于是往那个方向走一格，到左上角为止

第二种类型--最长公共子串

其实本质上是一样的，只不过子串必须是连续的，而子序列并不一定连续，所以只要改一个地方就好了，就是当匹配失败时（s1[i-1]!=s2[j-1]）直接赋0，同时，注意最值更新，途中更新不了，只能全部做完以后开两重for，一个个查找，看两个序列分别截止长度多少时算出来的最长公共子串最长。。。

这里有一道公共子串和公共子序列混合的题目，但其实只需要变个参数就行了

[Problem - 1159](https://acm.hdu.edu.cn/showproblem.php?pid=1159)

for (int i = 1; i <= n1; ++i)
    for (int j = 1; j <= n2; ++j)
