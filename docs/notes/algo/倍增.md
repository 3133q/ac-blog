# 倍增

倍增（Binary Lifting）是一种把「一步步走」优化成「翻倍跳」的通用技巧，核心是把任意整数拆成二进制，用 `log n` 次跳跃替代 `n` 步。

## 核心思想

任何非负整数都能拆成若干 `2^k` 的和，例如 `13 = 8 + 4 + 1 = 2^3 + 2^2 + 2^0`。

所以我们只要预处理出「从当前位置前进 2^k 步之后落在哪」，查询时按二进制从高到低拆解，就能把线性复杂度压到 `O(log n)`。

## 应用一：快速幂

求 `a^b mod p`，把指数 `b` 拆成二进制，底数不断平方：

```cpp
long long qpow(long long a, long long b, long long p) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
```

## 应用二：ST 表

ST 表预处理 `f[i][j]` 表示从 `i` 开始、长度为 `2^j` 的区间最值，本质也是倍增思想，详见 [ST表](/notes/algo/RMQ/ST表)。

## 应用三：树上倍增求 LCA

树上倍增是最经典的倍增应用。设 `up[u][k]` 表示节点 `u` 向上跳 `2^k` 步到达的祖先。

```cpp
const int LOG = 20; // 2^20 > 1e6
vector<vector<int>> up(n + 1, vector<int>(LOG));
vector<int> depth(n + 1);

void dfs(int u, int fa) {
    up[u][0] = fa;
    for (int k = 1; k < LOG; k++)
        up[u][k] = up[up[u][k - 1]][k - 1];
    for (int v : g[u])
        if (v != fa) {
            depth[v] = depth[u] + 1;
            dfs(v, u);
        }
}

int lca(int a, int b) {
    if (depth[a] < depth[b]) swap(a, b);
    // 把 a 提到和 b 同深度
    for (int k = LOG - 1; k >= 0; k--)
        if (depth[a] - (1 << k) >= depth[b])
            a = up[a][k];
    if (a == b) return a;
    // 一起往上跳，跳到 LCA 的下一层
    for (int k = LOG - 1; k >= 0; k--)
        if (up[a][k] != up[b][k]) {
            a = up[a][k];
            b = up[b][k];
        }
    return up[a][0];
}
```

## 小结

倍增的关键在于：**预处理出 2^k 步的信息，查询时用二进制拆解**，从而把 `O(n)` 降到 `O(log n)`。凡是能「预处理翻倍信息 + 二进制拆分」的问题，都可以考虑倍增。
