# 拓扑排序

## 引入

- 学习课程时，必须先学完 “高等数学” 才能学 “数据结构”，先学 “数据结构” 才能学 “算法”；
- 项目开发时，必须先完成 “需求分析” 才能开始 “架构设计”，先完成 “架构设计” 才能进行 “编码开发”；
- 任务调度时，必须先完成 “准备工作” 才能执行 “核心任务”，先执行 “核心任务” 才能进行 “收尾工作”。

这些场景的共同特点是“存在依赖关系”--某些事件必须在其他事件完成后才可发生，而在图论中，这种有依赖关系的事件，可以用有向无环图（DAG）来建模，也就是使用拓扑排序

## 定义

有向无环图：

- **有向图**：边带有方向的图，即边 **`<u, v>`** 表示**从顶点 `u` 到顶点 `v` 的单向关系**（比如 “学完 u 才能学 v”）；
- **无环图**：图中**不存在回路（环）**，即不存在一条从某个顶点出发，经过若干条边后能回到自身的路径；
- **有向无环图（DAG）**：同时满足 “有向” 和 “无环” 的图，是拓扑排序的唯一适用场景。
- ![img](https://developer.qcloudimg.com/http-save/yehe-100000/a24fba0bfb7ac646817b64f470850e88.png)

拓扑排序是对 DAG 图的顶点进行排序的过程，排序后的顶点序列需满足：

>  对于图中的任意一条有向边 **`<u, v>`**，顶点 `u` 在序列中一定位于顶点 `v` 之前。 简单来说，拓扑排序的结果是一个 “满足所有依赖关系的顶点序列”。

当然，对于拓扑排序后的结果，可能会多种多样，结果不固定。。

## 应用

1. **课程安排**：根据课程先修关系，安排合理的学习顺序；
2. **任务调度**：根据任务依赖关系，安排任务的执行顺序（比如项目开发流程）；

4. **依赖包安装**：软件安装时，根据依赖关系（比如安装 A 需要先安装 B），确定安装顺序；
5. **环检测**：判断图中是否存在环（比如检测循环依赖）。

> 对于环检测还是很实用的，比起繁琐的DFS，我还是更偏爱拓扑

拓扑排序实现可以使用两种算法，Kahn和DFS深度遍历

## kahn算法

### 基本思想

基于顶点的入度进行排序，入度是指的是指向该顶点边的条数

1. **初始化**：计算所有顶点的入度，将入度为 0 的顶点（没有任何依赖，可直接开始的活动）加入队列；
2. 迭代处理
   - 取出队头顶点 `u`，将其加入拓扑排序序列；
   - 遍历 `u` 的所有邻接顶点 `v`（即依赖于 `u` 的活动），删除边 `<u, v>`（相当于完成了 `u`，解除了对 `v` 的一个依赖）；
   - 若 `v` 的入度减为 0（所有依赖都已完成），将 `v` 加入队列；
3. **终止条件**：队列为空。此时，若拓扑排序序列的长度等于顶点数，则排序成功（图为 DAG）；否则，排序失败（图中存在环）。

### 例子

对于图

1-&gt;2

2-&gt;4

1-&gt;4

1-&gt;3

3-&gt;5

处理的时候，刚开始inq[1]=0   inq[2]=1   inq[4]=2   inq[3]=1   inq[5]=1

一开始会选择1去入队，然后遍历1的邻接点（2,3,4）1出队相当于把1和他连着的边全部消失，自然入度也得减一，所以2,3,4的入度分别减一，然后看看是否有入度为0的，然后入队，就是一个循环找优先级的过程，最后能够把顺序排好。。。

[B3644 【模板】拓扑排序 / 家谱树 - 洛谷](https://www.luogu.com.cn/problem/B3644)

### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
#include<queue>
#include<vector>
using namespace std;
const int N=1001;
int main(){
	int n,j,total=0;
	std::cin>>n;
	vector<int>inq(n+1);
	vector<int>topo(n+1);
	vector<int>edge[N];
	for(int i=1;i<=n;i++){
		while(std::cin>>j&&j!=0){
			edge[i].push_back(j);
			inq[j]++;
		}
	}
	queue<int>q;
	for(int i=1;i<=n;i++){
		if(inq[i]==0) q.push(i);
	}
	while(!q.empty()){
		int u=q.front();
		q.pop();
		topo[total++]=u;
		for(auto e:edge[u]){
			inq[e]--;
			if(inq[e]==0) q.push(e);
		}
	}
	for(int i=0;i<total;i++) std::cout<<topo[i]<<" ";
	std::cout<<'\n';
	return 0;
}
```

## DFS深度遍历

### 基本思路

1. 对每个未访问的顶点进行 DFS，遍历其所有邻接顶点；
2. 当一个顶点的所有邻接顶点都被访问完毕（即所有依赖都已处理），将该顶点加入拓扑序列（注意：是逆序加入，最终需要反转序列）；
3. 若 DFS 过程中发现回边（访问到已访问但未处理完的顶点），则说明图中存在环。

### 代码

```c++
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

const int N = 1e5 + 10;

int n, m;
vector<int> edges[N];    // 邻接表存储图
bool visited[N];         // 标记顶点是否已访问
bool in_stack[N];        // 标记顶点是否在当前DFS栈中（用于检测环）
vector<int> topo_order;  // 存储拓扑序列（逆序）
bool has_cycle = false;  // 标记图中是否存在环

// DFS函数：u为当前顶点
void dfs(int u) {
    visited[u] = true;
    in_stack[u] = true;  // 将u加入当前DFS栈

    // 遍历u的所有邻接顶点v
    for (int v : edges[u]) {
        if (!visited[v]) {
            dfs(v);
            if (has_cycle) return;  // 若已发现环，直接返回
        } else if (in_stack[v]) {
            // 发现回边，存在环
            has_cycle = true;
            return;
        }
    }

    // u的所有邻接顶点都已处理完毕，加入拓扑序列
    in_stack[u] = false;  // 从当前DFS栈中移除
    topo_order.push_back(u);
}

// 拓扑排序的DFS实现
void topo_sort_dfs() {
    // 初始化
    memset(visited, false, sizeof visited);
    memset(in_stack, false, sizeof in_stack);
    has_cycle = false;
    topo_order.clear();

    // 对每个未访问的顶点执行DFS
    for (int i = 1; i <= n; i++) {
        if (!visited[i] && !has_cycle) {
            dfs(i);
        }
    }

    // 若不存在环，反转拓扑序列（因为DFS是逆序加入的）
    if (!has_cycle) {
        reverse(topo_order.begin(), topo_order.end());
    }
}

int main() {
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        edges[u].push_back(v);
    }

    // 执行DFS版拓扑排序
    topo_sort_dfs();

    if (has_cycle) {
        cout << "图中存在环，无法进行拓扑排序！" << endl;
    } else {
        cout << "拓扑排序成功，序列为：";
        for (int i = 0; i < topo_order.size(); i++) {
            cout << topo_order[i] << " ";
        }
        cout << endl;
    }

    return 0;
}
```

### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
#include<vector>
#include<queue>
using namespace std;
const int N=600;
int has[N],inq[N];
vector<int>edge[N];
int main(){
	int n,x,m,y,ans=0;
	std::cin>>n;
	for(int i=1;i<=n;i++){
		std::cin>>x>>m;
		has[x]=1;
		for(int j=0;j<m;j++){
			std::cin>>y;
			edge[x].push_back(y);
			inq[y]++;
		}
	}
	queue<int>q;
	for(int i=0;i<=500;i++){
		if(has[i]&&inq[i]==0) q.push(i);
	}
	while(!q.empty()){
		int u=q.front();
		q.pop();
		ans++;
		for(auto e:edge[u]){
			if(has[e]&&inq[e]==0) q.push(e);
		}
	}
	if(ans>=n){
		std::cout<<"YES"<<'\n';
		return 0;
	}
	else std::cout<<n-ans<<'\n';
	return 0;
}
```

夹杂dp思想

[P1113 [USACO02FEB\] 杂务 - 洛谷](https://www.luogu.com.cn/problem/P1113)

核心就是要是这件杂务有牵绊也就是需要等待上一件事完成之后才能做时，使用一个数组更新最大值，将彼此的联系画成图之后，因为每件事都有可能会有需要准备的工作，所以如果选择这一条边，那么dp[e]=max(dp[e],dp[u]+len[e]) 也就是取一个最大值，这里之所以更新最大值，是因为采用拓扑的思想已经是最优，在这个前提下，需要保证所有杂事都能做完才是最重要的。

### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
#include<vector>
#include<queue>
using namespace std;
const int N=1e4+2;
vector<int>edge[N];
int len[N],inq[N],topo[N],dp[N];
int main(){
	int n,m,k,j,total=0;
	std::cin>>n;
	for(int i=1;i<=n;i++){
		std::cin>>m>>k;
		len[m]=k;
		dp[m]=k;
		while(std::cin>>j&&j!=0) {
			edge[m].push_back(j);
			inq[j]++;
		}
	}
	int t=0;
	queue<int>q;
	for(int i=1;i<=n;i++){
		if(inq[i]==0) q.push(i);
	}
	while(!q.empty()){
		int u=q.front();
		q.pop();
		t=max(t,dp[u]);
		for(auto e:edge[u]){
			dp[e]=max(dp[e],dp[u]+len[e]);
			inq[e]--;
			if(inq[e]==0){
				q.push(e);
			}
		}
	}
	int ans=0;
	std::cout<<t;
	return 0;
}
```

[P4017 最大食物链计数 - 洛谷](https://www.luogu.com.cn/problem/P4017)

同样，采取dp夹杂，对于一个食物链，它要我们计算食物链的种数，而非长度，可以这么想，遍历到一个相邻节点的时候，以它上一个节点为末尾的食物链同样可以累加到这一个节点，所以dp[e]=dp[e]+dp[u]

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
#include<vector>
#include<queue>
using namespace std;
const int N=1e4+2;
const int mod=80112002;
vector<int>edge[N];
int inq[N],out[N],dp[N];
int main(){
	int n,m,x,y;
	std::cin>>n>>m;
	for(int i=1;i<=m;i++){
		std::cin>>x>>y;
		edge[x].push_back(y);
		inq[y]++;
		out[x]++;
	}
	queue<int>q;
	for(int i=1;i<=n;i++){
		if(inq[i]==0){
			q.push(i);
			dp[i]=1;
		}
	}
	while(!q.empty()){
		int u=q.front();
		q.pop();
		for(auto e:edge[u]){
			dp[e]=(dp[e]+dp[u])%mod;
			inq[e]--;
			if(inq[e]==0) q.push(e);
		}
	}
	int r=0;
	for(int i=1;i<=n;i++){
		if(out[i]==0) r=(r+dp[i])%mod;
	}
	std::cout<<r;
	return 0;
}
```

最后给出判断是否存在环的方法

使用拓扑排序可以判断一个无向图中是否存在环，具体步骤如下：

1. 求出图中所有结点的度。
2. 将所有度 &lt;= 1 的结点入队。（独立结点的度为 0）
3. 当队列不空时，弹出队首元素，把与队首元素相邻节点的度减一。如果相邻节点的度变为一，则将相邻结点入队。
4. 循环结束时判断已经访问的结点数是否等于 n。等于 n 说明全部结点都被访问过，无环；反之，则有环。

有向图的话，把入度改为等于0的时候入队就行了

### 代码（有向）

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<vector>
#include<climits>
#include<queue>
using namespace std;
const int N=1e6+2;
vector<int>edge[N];
int topo[N],inq[N],vis[N];
int main(){
	int n,m,x,y;
	std::cin>>n>>m;
	for(int i=1;i<=m;i++){
		std::cin>>x>>y;
		edge[x].push_back(y);
		inq[y]++;
	}
	queue<int>q;
	for(int i=1;i<=n;i++){
		if(inq[i]==0) q.push(i);
	}
	int ans=1;
	while(!q.empty()){
		int u=q.front();
		q.pop();
		for(auto e:edge[u]){
			ans++; 
			inq[e]--;
			if(inq[e]==0) q.push(e);
		}
	}
	if(ans==n) std::cout<<"NO";
	else std::cout<<"YES";
	return 0;
}
```
