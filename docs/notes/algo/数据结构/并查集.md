## 引入

我们可以先看看这道题：

[P1551 亲戚 - 洛谷](https://www.luogu.com.cn/problem/P1551)

### 大意

<img src="/images/image-20260228104701991.png" alt="image-20260228104701991" style="zoom:80%;" />

很明显可以看出来题目本意就是一个合并的过程，x，y是亲戚，那么merge(x,y)，如果y，z是亲戚，那么merge(y,z)，但这里注意，合并过程是需要动态调整的，比如x，y是亲戚，y，z是亲戚，那么他们三得连在一块，这就需要一个分组的操作了，把同类的分到一组，然后最后直接查找就行了

## 正题

### 介绍

并查集的重要思想在于，**用集合中的一个元素代表集合**。我曾看过一个有趣的比喻，把集合比喻成**帮派**，而代表元素则是**帮主**。接下来我们利用这个比喻，看看并查集是如何运作的。

<img src="https://pic2.zhimg.com/v2-09fa3fa35e5411444b327d9cb9a31057_1440w.jpg" alt="img" style="zoom:80%;" />

最开始，所有大侠各自为战。他们各自的帮主自然就是自己。*（对于只有一个元素的集合，代表元素自然是唯一的那个元素）*

现在1号和3号比武，假设1号赢了（这里具体谁赢暂时不重要），那么3号就认1号作帮主*（合并1号和3号所在的集合，1号为代表元素）*。

<img src="https://pic4.zhimg.com/v2-3bf6c1a6ecf87fa93f4dbab2012446c7_1440w.jpg" alt="img" style="zoom:80%;" />

现在2号想和3号比武*（合并3号和2号所在的集合）*，但3号表示，别跟我打，让我帮主来收拾你*（合并代表元素）*。不妨设这次又是1号赢了，那么2号也认1号做帮主。

<img src="https://pic4.zhimg.com/v2-be12a6c795572d2acd77dcd49de35127_1440w.jpg" alt="img" style="zoom:80%;" />

现在我们假设4、5、6号也进行了一番帮派合并，江湖局势变成下面这样：

<img src="https://pic3.zhimg.com/v2-3c353bc781c7f3553079d541a9cfdc28_1440w.jpg" alt="img" style="zoom:80%;" />

现在假设2号想与6号比，跟刚刚说的一样，喊帮主1号和4号出来打一架（帮主真辛苦啊）。1号胜利后，4号认1号为帮主，当然他的手下也都是跟着投降了。

<img src="https://pic1.zhimg.com/v2-6362d8b13705d5ba17b19cdeee453022_1440w.jpg" alt="img" style="zoom:80%;" />

好了，比喻结束了。如果你有一点图论基础，相信你已经觉察到，这是一个**树**状的结构，要寻找集合的代表元素，只需要一层一层往上访问**父节点**（图中箭头所指的圆），直达树的**根节点**（图中橙色的圆）即可。根节点的父节点是它自己。我们可以直接把它画成一棵树：

### 优化点

**一.路径压缩**

可以看出来，如果直接随意合并的话，这棵树会越来越长，那么最后find操作找他们的父节点的时候，效率就会非常低，所以我们使用路径压缩，记录每个结点的秩，考虑把秩少的合并到多的上面，比如这样：

<img src="https://pic4.zhimg.com/v2-d3ff42bb79a6bc751f47daf3fc70e0d9_1440w.jpg" alt="img" style="zoom:80%;" />

<img src="https://pic2.zhimg.com/v2-96fbb25365b43f0a109bec6d55b3b899_1440w.jpg" alt="img" style="zoom:80%;" />

肯定使用第二种吧！！！

**二.find操作**

正常写find操作是这样的：

```c++
int find(int x)
{
    if(fa[x] == x)
        return x;
    else
        return find(fa[x]);
}
```

可以简写，如下：

```c++
int find(int x)
{
    return x == fa[x] ? x : (fa[x] = find(fa[x]));
}
```

> 注意，当找到的两个节点秩相同并且父节点不同，那么秩要加一，看看下图理解

<img src="https://pic3.zhimg.com/v2-de356190829600f438058e8615c7a5ac_1440w.jpg" alt="img" style="zoom:80%;" />

<img src="https://pic3.zhimg.com/v2-a829932f008f000440942cb8df393662_1440w.jpg" alt="img" style="zoom:80%;" />

显然树的深度增加了1。另一种合并方式同样会让树的深度+1。

### 代码

```c++
#include<bits/stdc++.h>
using namespace std;
const int N=1e4+2;
int rank1[N],fa[N],n;
inline void init(){
	for(int i=1;i<=n;i++){
		rank1[i]=1;
		fa[i]=i;
	}
}
int find(int i){
	return fa[i]==i?fa[i]:(fa[i]=find(fa[i]));
}
void merge(int i,int j){
	int x=find(i),y=find(j);
	if(rank1[x]<=rank1[y]) fa[x]=y;
	else fa[y]=x;
	if(rank1[x]==rank1[y]&&x!=y) rank1[y]++;
	return ;
}
int main(){
	int m,q,x,y,x1,y1; 
	std::cin>>n>>m>>q;
	init();
	for(int i=1;i<=m;i++){
		std::cin>>x>>y;
		merge(x,y);
	}
	for(int i=1;i<=q;i++){
		std::cin>>x1>>y1;
		if(find(x1)==find(y1)) std::cout<<"Yes"<<'\n';
		else std::cout<<"No"<<'\n';
	}
	return 0;
}
```

### 一

经典模板题

[P3367 【模板】并查集 - 洛谷](https://www.luogu.com.cn/problem/P3367)

#### 代码

```c++
#include<iostream>
#include<cstring>
#include<algorithm>
#include<climits>
#define ll long long
using namespace std;
const int N=1e6+2;
int n,m,z,x,y,r[N],fa[N];
inline void init(){
	for(int i=1;i<=n;i++){
		r[i]=1;
		fa[i]=i;
	}
}
int find(int i){
	return fa[i]==i?fa[i]:(fa[i]=find(fa[i]));
}
void merge(int i,int j){
	int x=find(i),y=find(j);
	if(r[x]<=r[y]) fa[x]=y;
	else fa[y]=x;
	if(r[x]==r[y]&&x!=y) r[y]++;
	return ;
}
int main(){
	std::cin>>n>>m;
	init();
	for(int i=1;i<=m;i++){
		std::cin>>z;
		if(z==1) {
			std::cin>>x>>y;
			merge(x,y);
		}
		if(z==2){
			std::cin>>x>>y;
			if(find(x)==find(y)){
				std::cout<<"Y"<<'\n';
				continue;
			}
			else{
				std::cout<<"N"<<'\n';
				continue;
			}
		}
	} 
	return 0;
}
```

### 二

小升级

[P1536 村村通 - 洛谷](https://www.luogu.com.cn/problem/P1536)

#### 大意

<img src="/images/image-20260228144714596.png" alt="image-20260228144714596" style="zoom:80%;" />

#### 分析

其实本质上就是判断两个城镇之间是否存在道路，若不存在则需要建立，而且道路之间可以互通，这不就是并查集的思路吗？？？

把建边过程看成merge操作，然后不断合并，最后看看需要合并几次就好了

#### 代码

```c++
#include<iostream>
#include<cstring>
#include<algorithm>
#include<climits>
using namespace std;
const int N=3001;
int n,m,x,y,r[N],fa[N];
inline void init(){
	for(int i=1;i<=n;i++){
		r[i]=1;
		fa[i]=i;
	}
}
int find(int i){
	return fa[i]==i?fa[i]:(fa[i]=find(fa[i]));
}
void merge(int i,int j){
	int x=find(i),y=find(j);
	if(r[x]<=r[y]) fa[x]=y;
	else fa[y]=x;
	if(r[x]==r[y]&&x!=y) r[y]++;
	return ;
}
int main(){
	while(1){
		std::cin>>n;
		if(n==0) break;
		std::cin>>m;
	    int sum=0;
		init();
		for(int i=1;i<=m;i++){
			std::cin>>x>>y;
			merge(x,y);
		}
		for(int i=1;i<=n;i++){
			for(int j=i+1;j<=n;j++){
				if(find(i)!=find(j)) {
					sum++;
					merge(i,j);
				}
			}
		}
		std::cout<<sum<<'\n';
	}
	return 0;
}
```

### 三

再升级

[P1111 修复公路 - 洛谷](https://www.luogu.com.cn/problem/P1111)

#### 大意

<img src="/images/image-20260228145101941.png" alt="image-20260228145101941" style="zoom:80%;" />

#### 分析

这道题比起前面那题升级了一丢丢，相当于要判断在某个时间内，能把几条公路修完的同时保证任意两个公路是连通的 ，其实也就是多了步排序而已哈哈哈哈

#### 代码

```c++
#include<bits/stdc++.h>
using namespace std;
int n,m;
struct pt{
	int x,y,t;
}a[100020];
int fa[1002],k[1002];
bool cmp(pt a,pt b){
	return a.t<b.t;
}
inline void init(int n){
	for(int i=1;i<=n;i++){
		fa[i]=i;
		k[i]=1;
	}
}
int find(int x){
	return x==fa[x]?x:(fa[x]=find(fa[x]));
}
void merge(int i,int j){
	int x=find(i),y=find(j);
	if(k[x]<=k[y]) fa[x]=y;
	else fa[y]=x;
	if(k[x]==k[y]&&x!=y) k[y]++;
}
int main(){
	std::cin>>n>>m;
	init(n);
	for(int i=1;i<=m;i++) std::cin>>a[i].x>>a[i].y>>a[i].t;
	sort(a+1,a+1+m,cmp);
	int cnt=n;
	for(int i=1;i<=m;i++){
		if(find(a[i].x)!=find(a[i].y)){
			merge(a[i].x,a[i].y);
			cnt--;
		}
		if(cnt==1){
			std::cout<<a[i].t;
			return 0;
		}
	}
	std::cout<<-1;
	return 0;
}
```
