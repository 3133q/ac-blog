先看例题一，括号配对问题

问题大概描述：给定一个字符串，请检查字符串中仅由括号字符'['，']'，'('，')'组成的子序列是否构成合法括号序列，合法序列的定义如下：

∙ ∙空序列是合法括号序列；

∙ ∙如果 A 是合法括号序列，则 `(A)` 和 `[A]` 都是合法括号序列；

∙ ∙如果 A和 B都是合法括号序列，则它们的拼接 AB也是合法括号序列。

给出一个例子 abcd(])[efg  看这个字符串，提取括号相关子序列(])[  很明显，无法配对成功，false

理解题目意思后我们就可以开始解题了，其实这题思路不难，先找到左半边 ( 或者 [ ，然后如果后边有他的对应右半边，即配对成功，否则就不行，那这不是正好可以用栈去解吗，先入栈括号相关的左半边，然后如果栈里边存在它的左半部分，则将他出栈，最后如果栈为空，说明全部配对成功，否则配对失败。

下面给出代码：

```c++
#include <bits/stdc++.h>
using namespace std;
bool check(string s) {
    int len = s.size();
    stack<char> st;
    for(int i=0; i<len; i++) {
        if(s[i]=='(' || s[i] == '[') st.push(s[i]);
        else if(s[i] == ')') {
            if(st.empty() || st.top()!='(') return 0;
            st.pop();
        }
        else if(s[i] == ']') {
            if(st.empty() || st.top()!='[') return 0;
            st.pop();
        }
    }
    return st.empty();
}
int main(){
    string s; cin>>s;
    stack<char> st;
    if(check(s)) cout<<"true"<<endl;
    else cout<<"false"<<endl;
    return 0;
}

```

其实下一题（例题2）跟他是类似的，只不过加了一种形式而已

题目描述：给出一个仅由括号字符 ‘[’、‘]’、‘(’、‘)’、‘{’、‘}’ 的括号序列字符串 s，你需要判断字符串s是否是有效的括号序列，描述如下：

∙ ∙空序列是有效括号序列；
∙ ∙如果 A*A* 是有效括号序列，则 (A)、[A]和 A 都是有效括号序列；
∙ ∙如果 A*A* 和 B*B* 都是有效括号序列，则它们的拼接 AB 也是有效括号序列。

仔细想想这题还更简单，一来它只有括号字符，没有其他无效的（其实有也无所谓哈哈哈），只不过多了一个{}而已，多加几条语句即可。

看看代码：

```c++
class Solution {
public:
    bool isValid(string s) {
        stack<char>st;
        for(int i=0;i<s.size();i++){
            if(s[i]=='['||s[i]=='('||s[i]=='{') st.push(s[i]);
            else if(s[i]==']'){
                if(st.empty()||st.top()!='[') return false;
                st.pop();
            }
            else if(s[i]==')'){
                if(st.empty()||st.top()!='(') return false;
                st.pop();
            }
            else if(s[i]=='}'){
                if(st.empty()||st.top()!='{') return false;
                st.pop();
            }
        }
        return st.empty()?true:false;
    }
};
```

由于是练习模式，直接给了模板，直接写的函数部分。。。

下面是最后一题，例题三，这个有点难度

题目描述：请写一个整数计算器，支持加减乘三种运算和括号

计算器想必很简单，不过这里加入了括号运算。。。。。

比如说"(2 * (3-4)) * 5"   得先算括号里的，然后再相乘，其实进行括号运算也不难，关键得有一定的积累，比如下面说的神仙思路----递归！

因为我们要先算括号里的嘛，那不就可以先递归调用，先把括号里的表达式值算出来，然后储存一下，再进行后续运算，这么看，递归在这题可谓是杀疯了！下面看看代码就可以了：

```c++
class Solution {
  public:
    int solve(string s) {
        int res = 0; 
        stack<int> sum; 
        char sign ='+'; 
        int num = 0; 
        for (int i = 0; i < s.size(); i++) { 
            if (s[i] >= '0' && s[i] <= '9') 
                num = 10 * num + s[i] - '0'; 
            if (s[i] == '(') { 
                int left = i++, count =1; 
                while (count >0) { 
                    if (s[i] == '(') count++;
                    else if (s[i] == ')') count--;
                    i++;
                }
                num = solve(s.substr(left + 1,i - left - 2)); 
                i--;
            }
            if (i == s.size() - 1 || s[i] == '+' || s[i] == '-' ||s[i] == '*') { 
                if (sign == '+') sum.push(num); 
                else if (sign == '-') sum.push(-num); 
                else if (sign == '*') sum.top() *= num; 
                sign = s[i]; 
                num = 0; 
            }
        }
        while (!sum.empty()) { 
            res += sum.top();
            sum.pop();
        }
        return res; 
    }
};
```

注意，这里一开始赋值sign为’+‘是为了一开始能够添加该元素，理解为+2*7这种样子。
