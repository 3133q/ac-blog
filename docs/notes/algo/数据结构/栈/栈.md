栈是OI中常用的一种线性数据结构，栈的修改与访问是按照后进先出的原则进行的，因此栈常被称为后进先出表，简称LIFO表

首先让我们看看如何实现栈吧

对于线性结构，结构体是必不可少的。。。

```c++
typedef struct tree{
	int data[maxx];
	int top;
}Stack;
```

结构体的定义，data数据域，top表示栈顶

先讲相应的判断栈空，栈满操作

```c++
int empty(Stack* st){
	return st->top==-1;
}
```

定义结构体指针，若访问栈顶为-1（初始化就是-1）那么栈空，返回-1

```c++
int full(Stack* st){
	return st->top==maxx-1;
}
```

判断栈满，直接判断栈顶是否已经超过了最大容量。

```c++
void push(Stack* st,int x){
    if(full(st)) return ;
    else {
    	st->data[++st->top]=x;
    	len++;
	}
}
```

往栈中添加元素，直接指向栈顶的位置加一，随后添加元素即可，这里的len为了得到栈的元素数量

```c++
void pop(Stack* st){
    if(empty(st)==-1) return ;
    else {
    	st->top--;
    	len--;
	}
}
```

出栈，首先判断栈是否为空，为空的话没必要操作了，随后栈顶位置减一即可完成出栈。

```c++
int size(Stack* st){
    return len;
}
```

算出栈中元素数量

```c++
int query(Stack* st){
    if(empty(st)==-1) return -1;
    else return st->data[st->top];
}
```

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1e5+2;
int len=0;
typedef struct node{
    int data[N];
    int top;
}Stack;
void init(Stack* st){
	st->top=-1;
}
int empty(Stack* st){
    return st->top==-1;
}
int full(Stack* st){
    return st->top==N-1;
}
void push(Stack* st,int x){
    if(full(st)) return ;
    else {
    	st->data[++st->top]=x;
    	len++;
	}
}
void pop(Stack* st){
    if(empty(st)==-1) return ;
    else {
    	st->top--;
    	len--;
	}
}
int query(Stack* st){
    if(empty(st)==-1) return -1;
    else return st->data[st->top];
}
int size(Stack* st){
    return len;
}
int main() {
    Stack st;
    int n,x;
    std::cin>>n;
    init(&st);
    string s;
    for(int i=0;i<n;i++){
        std::cin>>s;
        if(s=="push"){
            std::cin>>x;
            push(&st,x);
            continue;
        }
        if(s=="size"){
            std::cout<<size(&st);
            std::cout<<'\n';
            continue;
        }
        if(s=="query"){
            if(empty(&st)){
                std::cout<<"Empty"<<'\n';
                continue;
            }
            else {
                std::cout<<query(&st)<<'\n';
                continue;
            }
        }
        if(s=="pop"){
            if(empty(&st)){
                std::cout<<"Empty"<<'\n';
                continue;
            }
            else pop(&st);
        }
    }
    return 0;
}
```

其实栈只要知道一下底层逻辑代码咋写就行了，实际上用STL就行了

上面这题就可以用STL

```c++
#include <iostream>
#include<stack>
using namespace std;
void solve(){
    stack<int> stk;
    int t;
    cin>>t;
    string s1;
    int num2;
    while(t--){
        cin>>s1;
        if(s1 =="push"){
            cin>>num2;
            stk.push(num2);
        }else if(s1 == "pop"){
            if(stk.empty()){
                cout<<"Empty"<<endl;
            }else{
                stk.pop();
            }
        }else if(s1 == "query"){
            if(stk.empty()){
                cout<<"Empty"<<endl;
            }else{
                cout<<stk.top()<<endl;
            }
        }else if(s1 == "size"){
            cout<<stk.size()<<endl;
        }
    }
}
int main() {
    solve();
    return 0;
}
```
