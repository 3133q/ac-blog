优先队列

所谓优先队列，比起普通队列的优点是--自动排序

一个优先队列声明的基本格式是：
**priority_queue&lt;结构类型&gt; 队列名;**

优先队列的基本函数

q.size();//返回q里元素个数 

q.empty();//返回q是否为空，空则返回1，否则返回0 

q.push(k);//在q的末尾插入k 

q.pop();//删掉q的第一个元素 

q.top();//返回q的第一个元素

示例   

```c++
#include<cstdio>
#include<queue>
using namespace std;
priority_queue <int> q;
int main()
{
	q.push(10),q.push(8),q.push(12),q.push(14),q.push(6);
	while(!q.empty())
		printf("%d ",q.top()),q.pop();
}
```

输出结果：14 12 10 8 6

说明，优先队列默认从大到小排序

扩展：默认的优先队列（结构体，重载小于）

```c++
struct node
{
	int x,y;
	bool operator < (const node & a) const
	{
		return x<a.x;
	}
};
```

这个node结构体有两个成员，x和y，它的小于规则是x小者小。

示例：

```c++
#include<cstdio>
#include<queue>
using namespace std;
struct node
{
	int x,y;
	bool operator < (const node & a) const
	{
		return x<a.x;
	}
}k;
priority_queue <node> q;
int main()
{
	k.x=10,k.y=100; q.push(k);
	k.x=12,k.y=60; q.push(k);
	k.x=14,k.y=40; q.push(k);
	k.x=6,k.y=80; q.push(k);
	k.x=8,k.y=20; q.push(k);
	while(!q.empty())
	{
		node m=q.top(); q.pop();
		printf("(%d,%d) ",m.x,m.y);
	}
}
```

输出：
`(14,40) (12,60) (10,100) (8,20) (6,80)`

它也是按照**重载后的小于规则**，从大到小排序的。

---------------------------------------------------------------------------------------------------------------------对于结构体内嵌比较函数，直接写比较函数中x表示当前的值，如果x&lt;a.x，那么就是从小到大排序，但是优先队列相反，也就是x&gt;a.x在优先队列中是从小到大排序

具体参考   [结构体内嵌比较函数bool operator &lt; (const node &x) const {} - ZERO- - 博客园](https://www.cnblogs.com/ZERO-/p/9347296.html)

---------------------------------------------------------------------------------------------------------------------

priority_queue &lt;int,vector&lt;int&gt;,less&lt;int&gt; &gt; p;
priority_queue &lt;int,vector&lt;int&gt;,greater&lt;int&gt; &gt; q;

**less是从大到小，greater是从小到大**。

代码：

```c++
#include<bits/stdc++.h>
using namespace std;
priority_queue<int,vector<int>,greater<int>> q;      	
int main(){
	int n,x;
	std::cin>>n;
	for(int i=1;i<=n;i++) {
		std::cin>>x;
		q.push(x);
	}
	int sum=0;
	while(q.size()!=1){
		int tmp=q.top();
		q.pop();
		int cmp=q.top();
		q.pop();
		sum+=(tmp+cmp);
		q.push(tmp+cmp);
	}
	std::cout<<sum;
	return 0;
}
```
