先看第二道例题，因为它更简单owo

题目描述：有长度为n的序列students=[s1,s2....sn]（只包含0/1），表示**队列**中第i名同学的编号，序列sandwiches=[t1,t2....tn]（只包含0/1），表示**栈顶至栈底**的三明治类型，每步操作如下：

若 s1=t1，则该学生取走该三明治并移出队列，三明治出栈；

否则，将队首学生移至队尾；   直到剩余学生不满足条件

*要求出无法拿到三明治的学生数*

想必你可以看出题目中特意加上了队列，栈这两个字眼，但其实你仔细想想，这道题其实跟这两玩意根本无关

首先演示一下样例吧       1 1 0 1     1 0 0 1

从第一个开始 1跟1匹配    两个1同时出去

下一个1跟0不匹配，1到队尾，0接上，0跟0匹配，两个0同时出去

下一个1跟0不匹配，滑至队尾，跟上来还是1，跟0不匹配，这样循环往复都不可能匹配成功，所以结束，有两个人无法拿到三明治

从演示很容易看出思路吧，我们可以先存储一下0跟1的个数，然后一个个匹配，如果匹配上了，对应数量减1，然后往后走，如果其中一个减到了0同时跟上的三明治编号也是它，那么就可以直接退出了，最后累加对应0跟1的总数即可。

让我们看看代码：

```c++
class Solution {
public:
    int countStudents(vector<int>& students, vector<int>& sandwiches) {
        // write code here
        int a[501];
        memset(a,0,sizeof(a));
        for(auto e:students) a[e]++;
        for(auto e:sandwiches){
            if((a[0]==0&&e==0)||(a[1]==0&&e==1)) break;
            a[e]--;
        }
        return a[0]+a[1];
    }
};
```

接着，我们看看第一道例题

描述：

牛牛的电脑上安装了一个机器翻译软件，它依次将每个英文单词替换为对应的中文含义。软件内部有 M个缓存单元，每个单元存放一个单词和译义。翻译某个单词时：

​    **∙** 如果缓存中已有该单词，则直接使用（缓存命中）；
​    **∙**否则需要到外存词典查找（缓存未命中），并将该单词及译义插入缓存：若缓存未满，则占用一个空闲单元；若缓存已满，则清除最早进入缓存的单词后插入新单词。

给定长度为 N的文章（由 N个整数编码表示单词），初始缓存为空，统计翻译过程中需要查词典的次数。

分析题目，其实很简单，给出一个单词后，先看看它是否存在，如果存在的话，continue即可，不然，就得加一次，然后对于缓存已满（即数量超限的时候），先删掉第一个元素，然后往后再插入新元素就可以了。

（其实你这么一想这道题用vector才是妙解。。。）

![img](https://dl4.weshineapp.com/gif/20230116/91ac9e09df30746d3ed06544e6ee84b8.gif?f=micro_)

看看代码：

```c++
#include <iostream>
#include<vector>
#include<cstring>
#include<algorithm>
using namespace std;

int main() {
    int m,n,x,s=0,hash[3001],total=0;
    std::cin>>m>>n;
    vector<int>a(m);
    for(int i=0;i<n;i++){
        std::cin>>x;
        if(hash[x]) continue;
        s++;
        if(total<m){
            a[total++]=x;
            hash[x]=1;
        }
        else if(total>=m){
            hash[a.front()]=0;
            a.erase(a.begin());
            a.push_back(x);
            hash[x]=1;
        }
    }
    std::cout<<s;
    return 0;
}
```
