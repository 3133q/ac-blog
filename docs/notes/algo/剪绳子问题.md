# 剪绳子问题

> 把一根绳子切成整数段，求各段长度乘积的最大值。

## 一、问题描述

给一根长为 $n$ 的绳子，剪成整数长度的 $m$ 段（$n,m > 1$），每段长度记为 $k[0], k[1], \dots, k[m]$，求 $k[0] \times k[1] \times \cdots \times k[m]$ 的最大值。

例如 $n = 8$，分成 $3, 3, 2$ 三段，乘积最大为 $18$。

---

## 二、解法一：动态规划

### 思路

- $n \le 3$ 时特判：$n=2 \to 1 \times 1 = 1$，$n=3 \to 1 \times 2 = 2$，直接返回 $n-1$
- 设 $dp[i]$ 为长度 $i$ 分段后的最大乘积
- 初始化 $dp[1]=1, dp[2]=2, dp[3]=3$（作为子段的"最大贡献值"）
- 从 $4$ 推到 $n$：$dp[i] = \max\limits_{j=1}^{i/2}(dp[i-j] \times dp[j])$

### 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> dp(n + 1, 0);
    if (n <= 3) {
        cout << n - 1;
        return 0;
    }
    dp[1] = 1, dp[2] = 2, dp[3] = 3;
    for (int i = 4; i <= n; i++)
        for (int j = 1; j <= n / 2; j++)
            dp[i] = max(dp[i], dp[i - j] * dp[j]);
    cout << dp[n];
    return 0;
}
```

## 三、解法二：数学推导

### 推导

设每段长度均为 $x$，$n = ax$，则乘积 $x^a = x^{n/x} = (x^{1/x})^n$。

令 $y = x^{1/x}$，求导得最大值在 $x = e \approx 2.718$ 处。

比较 $x=2$ 和 $x=3$：$2^{1/2} < 3^{1/3}$，所以应**尽可能切成 3**。

### 分类讨论

| $n \bmod 3$ | 示例（$n$） | 策略 | 乘积 |
|-------------|------------|------|------|
| $0$ | $6$ | 全切成 $3$ | $3^a$ |
| $1$ | $7 = 3+3+1$ | 少切一个 $3$，凑成 $4$ | $3^{a-1} \times 4$ |
| $2$ | $8 = 3+3+2$ | 余数 $2$ 单独成段 | $3^a \times 2$ |

### 代码

```cpp
class Solution {
public:
    int cuttingRope(int n) {
        if (n <= 3) return n - 1;
        int a = n / 3;
        if (n % 3 == 0) return pow(3, a);
        if (n % 3 == 1) return pow(3, a - 1) * 4;
        return pow(3, a) * 2;
    }
};
```

## 小结

| 解法 | 适用场景 |
|------|----------|
| 动态规划 | 通用，$n$ 不太大时简单直接 |
| 数学推导 | $n$ 极大时，$O(1)$ 计算 |
