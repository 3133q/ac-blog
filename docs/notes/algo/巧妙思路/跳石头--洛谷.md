巧思--解决动态划去数组中的元素

题目：[P2678 [NOIP 2015 提高组\] 跳石头 - 洛谷](https://www.luogu.com.cn/problem/P2678)

这道题由于二分的过程中要动态实现搬走石头的操作，这个操作我一开始的想法是：

一.简单点，用vector，然后如果这块石头不满足条件得搬走，那就erase，然后下一步

二.正常些，用数组标记，如果他要搬走，那就v数组标记一下，后面while循环直到找到还存在的石头

但这两种都相对复杂，麻烦，有出错的风险，下面看看巧思

既然我要一步步往后跳，这期间又要搬走不该存在的石头，以保证后面计算距离不会出错，那何尝不来一个指标，记录当前位置，如果能的话就往前更新值，不然直接跳过就行

我们来看看代码部分：

```c++
long long check(int x){
	int t=0,last=0;
	for(int i=0;i<=n;i++){
		if(a[i]-last<x) t++;
		else last=a[i];
	}
	return t<=m;
}
```
