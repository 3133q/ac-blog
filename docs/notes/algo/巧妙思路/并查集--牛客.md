[I-并查集_个人集训赛](https://ac.nowcoder.com/acm/contest/126768/I)

并查集模板题，关于前面并查集的写法就不多说了，都是很常规的操作，关键在于这道题的巧妙之处

先问了学生们总共属于几个班级？

看到这个问题很明确吧，开个for循环，每次读两个人，然后merge一下，后头再开for，看他的father是不是一样的，如果不是则计数器加一，最后可以得出总共属于几个班级。。。

但是后面又问了一个问题，人数最多的是哪个班级？

看到这个问题说实话，我当时懵了，如果开数组的话a[fa[i]]++？然后在a数组里找最大值，那就得使用max_element函数了，但这玩意我不太熟练，所以没使用，又想想，如果把他俩拆开来处理，先求解总共属于几个班级，然后遍历找最大元素，岂不是太麻烦了点qwq

这里给出此题的妙解，利用map容器存储键值对的特性

将每个学生对应的父节点作为map的键，然后对应班级的人数作为map的值，利用map支持size操作，很轻易得出班级的个数，然后通过遍历也能轻松找出人数最多的班级

代码如下

```c++
    map<int,int>mp;
    for(int i=0;i<n;i++) merge(i,fa[i]);
    for(int i=0;i<n;i++) mp[fa[i]]++;
    for(auto [x,y]:mp) maxx=max(maxx,y);
    std::cout<<mp.size()<<" "<<maxx;
```

该题的完整代码如下：

```c++
#include<bits/stdc++.h>
using namespace std;
int n,m,u,v;
int rank1[200001],fa[200001];
inline void init(){
    for(int i=0;i<n;i++){
        fa[i]=i;
        rank1[i]=1;
    }
}
int find(int x){
    return (x==fa[x])? x : (fa[x]=find(fa[x]));
}
void merge(int i,int j){
    int x=find(i);
    int y=find(j);
    if(rank1[x]<=rank1[y]) fa[x]=y;
    else fa[y]=x;
    if(rank1[x]==rank1[y]&&x!=y) rank1[y]++;
}
int main(){
    std::cin>>n>>m;
    init();
    for(int i=0;i<m;i++){
        std::cin>>u>>v;
        merge(u,v);
    }
    int maxx=-1e5+2;
    map<int,int>mp;
    for(int i=0;i<n;i++) merge(i,fa[i]);
    for(int i=0;i<n;i++) mp[fa[i]]++;
    for(auto [x,y]:mp) maxx=max(maxx,y);
    std::cout<<mp.size()<<" "<<maxx;
    return 0;
}
```
