## 2.分析

其实也就是说每次给出一个区间，需要对这个区间进行一个操作，然后把最终的数组输出，这种题很明显，用差分去做嘛，因为线段树没有必要，没说要支持查询，只要输出最终结果就行

一次差分肯定不行，因为它不是单纯那种一个区间统一加或者减一个数，而是用到一个山峰状的趋势，所以我们考虑二阶差分，去看看规律

比如[2,6]吧，区间长度为奇数

0 0 0 0 0 0 0 --&gt; 0 1 2 3 2 1 0 0

一阶差分：0 1 1 1 1 -1 -1 0

二阶差分：0 1 0 0 0 -2 0 1

可以看到变化的数字有三个，即三个位置

再举一个[2,5]，区间长度为偶数

0 0 0 0 0 0 0 -&gt; 0 1 2 2 1 0 0

一阶差分：0 1 1 0 -1 -1 0

二阶差分：0 1 0 -1 -1 0 1

可以看到有四个位置发生了变化，但是仔细看可以发现，都与彼此的中心位置有关

归纳出：左中点 l+(r-l)/2

​               右中点 l+(r-l+1)/2

变化的是：a[l]++   a[mid1+1]--   a[mid2+1]--   a[r+2]++

然后写代码即可

## 代码

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
void solve(){
    int n,m;
    std::cin>>n>>m;
    vector<int>a(n+10,0);
    int l,r;
    for(int i=1;i<=m;i++){
        std::cin>>l>>r;
        int mid1=l+(r-l)/2;
        int mid2=l+(r-l+1)/2;
        a[l]++;
        a[r+2]++;
        a[mid1+1]--;
        a[mid2+1]--;
    }
    for(int i=1;i<=n;i++) a[i]+=a[i-1];
    for(int i=1;i<=n;i++) a[i]+=a[i-1];
    for(int i=1;i<=n;i++) std::cout<<a[i]<<" ";
    std::cout<<'\n';
    return ;
}
signed main(){
    int t;
    std::cin>>t;
    for(int i=0;i<t;i++) solve();
    return 0;
}
```
