## 2.分析

其实就是说我有一个方向数组，U，D，L，R表示四个方向，我现在需要删除k个字符，要使最终到达的位置和原点之间的曼哈顿距离最长，需要怎么删除

理解过来就是使最终的|x0|+|y0|最大，这里我们可以这么考虑

最大位置一定是偏向于某一个具体的象限，我们考虑四个方向：

**右上角 (x≥0, y≥0)**：好方向是U，R，坏方向是D，L

**左上角 (x≤0, y≥0)**：好方向是 U, L，坏方向是 D, R。

**右下角 (x≥0, y≤0)**：好方向是 D, R，坏方向是 U, L。

**左下角 (x≤0, y≤0)**：好方向是 D, L，坏方向是 U, R。

只需要分别计算一下，往哪里走能最大即可

假设让他往右上角走，那么D，L就是坏字符

设原字符串坏字符总数为B

  如果我们可删除的次数k&gt;=B，那么我们直接把全部坏字符删掉，剩下全是好字符，此时无论再额外删哪个好字符，都无所谓，因为贡献都是1

  如果我们可删除的次数k&lt;B，那么我们只能删除k个坏字符，剩下B-k个坏字符，不仅不贡献，还会抵消掉B-k个好字符

总结：最终最大距离=(n-k)-2*max(0,B-k)

我们只需要分别算出四个方向为目标时所能到的最大距离，最后输出最大的即可。。

## 3.代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<cmath>
#include<vector>
#include<map>
#include<algorithm>
#include<climits>
#define int long long
using namespace std;

signed main(){
    int n,k;
    std::cin>>n>>k;
    string s;
    std::cin>>s;

    int cu=0,cd=0,cl=0,cr=0;
    for(int i=0;i<s.size();i++){
        if(s[i]=='U') cu++;
        else if(s[i]=='D') cd++;
        else if(s[i]=='L') cl++;
        else if(s[i]=='R') cr++;
    }

    int m1=(cr-cl+cu-cd)+2*min(k,cl+cd)-k;
    int m2=(cr-cl-cu+cd)+2*min(k,cl+cu)-k;
    int m3=(-cr+cl+cu-cd)+2*min(k,cr+cd)-k;
    int m4=(-cr+cl-cu+cd)+2*min(k,cr+cu)-k;

    int mx=m1;
    int type=1;
    if(m2>mx) { mx=m2; type=2; }
    if(m3>mx) { mx=m3; type=3; }
    if(m4>mx) { mx=m4; type=4; }

    int rL=0,rD=0,rR=0,rU=0;
    int rem=k;

    if(type==1){
        rL=min(rem,cl); rem-=rL;
        rD=min(rem,cd); rem-=rD;
        rR=min(rem,cr); rem-=rR;
        rU=min(rem,cu); rem-=rU;
    }
    else if(type==2){
        rL=min(rem,cl); rem-=rL;
        rU=min(rem,cu); rem-=rU;
        rR=min(rem,cr); rem-=rR;
        rD=min(rem,cd); rem-=rD;
    }
    else if(type==3){
        rR=min(rem,cr); rem-=rR;
        rD=min(rem,cd); rem-=rD;
        rL=min(rem,cl); rem-=rL;
        rU=min(rem,cu); rem-=rU;
    }
    else{
        rR=min(rem,cr); rem-=rR;
        rU=min(rem,cu); rem-=rU;
        rL=min(rem,cl); rem-=rL;
        rD=min(rem,cd); rem-=rD;
    }

    int kU=cu-rU;
    int kD=cd-rD;
    int kL=cl-rL;
    int kR=cr-rR;

    string ss="";
    for(int i=0;i<s.size();i++){
        if(s[i]=='U'&&kU>0){ ss+=s[i]; kU--; }
        else if(s[i]=='D'&&kD>0){ ss+=s[i]; kD--; }
        else if(s[i]=='L'&&kL>0){ ss+=s[i]; kL--; }
        else if(s[i]=='R'&&kR>0){ ss+=s[i]; kR--; }
    }

    std::cout<<ss<<"\n";
    return 0;
}
```
