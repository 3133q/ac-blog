## 2.分析

题目的意思很好理解，就是构造字符串，满足0跟1的数量相差&lt;=1，并且在该字符串中，恰好有k对相邻的相等字符

这道题略微带一点正难则反的想法，因为题目说的是要求正好有k对相邻的相等字符，但是这就有很多种情况了，比如说我把这么多对全部放在一处，或者是我可以均分，分到多处，但这样有个问题就是我不能保证我这样随便分了之后能成功构造出字符串！！

所以得反过来想，要求相邻相等，那我们能不能反过来想，变成相邻不相等呢？因为相邻不相等说明一个东西，就是分块，字符发生了切换

一个长度为n的字符串，里面共有n-1对相邻字符，既然有k对是相等的，那么剩下的全都是不相等的，字符发生切换次数=(n-1)-k

这里的段就是我们所说的交替块，也就是说

交替块数量b=切换次数+1，代入可得b=n-k

这就是分块思想的核心！！

我们规定0的总数c0=(n+1)/2，1的总数=n/2

0-块的数量=(b+1)/2，1-块的数量=b/2

因为得保证每一块至少一个字符，如果当n&gt;=2，并且k=n-1，也就意味着所有字符必须一样，肯定不成立吧，所以直接输出-1

有解的话，我们直接贪心策略，先往每个块先塞一个0或者1，然后把多余的直接扔进第一个0-块和第一个1-块即可

## 3.代码

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
void solve(){
	int n,k;
	std::cin>>n>>k;
	if(n>=2&&k==n-1){
		std::cout<<-1<<'\n';
		return ;
	}
	int b=n-k;
	int c0=(n+1)/2;
	int c1=n/2;
	int b0=(b+1)/2;
	int b1=b/2;
	string s="";
	for(int i=0;i<b;i++){
		if(i%2==0){
			int count=(i==0)?(c0-b0+1):1;
			for(int j=0;j<count;j++) s+='0';
		}
		else{
			int count=(i==1)?(c1-b1+1):1;
			for(int j=0;j<count;j++) s+='1';
		}
	}
	std::cout<<s<<'\n';
}
signed main(){
	int t;
	std::cin>>t;
	for(int i=0;i<t;i++) solve();
	return 0;
}
```
