## 2.分析

理解为给出ai，bi，它们共同构成一个新数组，这个数组按照ai的顺序，对于每个ai，总共有bi个，由此构成最终的序列，题目问，若取任意个互不相邻的元素，能达到的最大和为多少

本质上就是取舍，如果取了这个数的最后一个，那么下一个数的开头就无法选了，所以 这里就得考虑多种状态

可以这么想，由于n的范围是2e5，我们最多可以动手O(k*n)，这时，可以想到如果我们不知道如何取舍，那不妨直接枚举所有情况

当ai&gt;0，我们自然希望选的越多越好

当ai&lt;=0，我们希望选的越少越好（最好一个都不选），但是段与段之间是互相联系的，第i段的第一个元素是否被选择，取决于第i-1段的最后一个元素是否被选择，第i段的最后一个元素是否被选择，也会决定第i+1段的第一个元素是否被选择

使用dp状态转移

dp[0]表示在前i段中，不选择第i段最后一个元素时，所能获得最大和

dp[1]表示在前i段中，选择第i段最后一个元素时，所能获得最大和

对于第i段（长度为b，元素值为a），我们穷举他的端点状态

v1：第i段第一个元素是否选择（0不选，1选）

vb：第i段最后一个元素是否选择，对于每一组合法的(v1,vb)，我们在这一段内能获得最大和，设这一段可以选出最多元素max_elem，最少合法元素为min_elem

如果b=1，v1必须等于vb

如果b=2，v1=1和vb=1不合法

对于b&gt;=3，

  如果v1=0，vb=0，max_elem=(b-1)/2

  如果v1!=vb，max_elem=b/2

  如果v1=1，vb=1，max_elem=(b+1)/2

若a&lt;=0，即尽可能选少，我们只需选被迫的端点即可，即min_elem=v1+vb



## 3.代码

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int INF=1e18;
int get_max_sum(int b,int a,int v1,int vb){
    if(b==1){
        if(v1!=vb) return -INF;
        return v1?a:0;
    }
    if(b==2){
        if(v1==1&&vb==1) return -INF;
        return (v1+vb)*a;
    }
    int max_elems=0;
    if(v1==0&&vb==0) max_elems=(b-1)/2;
    else if(v1!=vb) max_elems=b/2;
    else max_elems=(b+1)/2;
    int min_elems=v1+vb;
    return (a>0)?(max_elems*a):(min_elems*a);
}
signed main(){
    int n;
    std::cin>>n;
    vector<int>a(n+1),b(n+1);
    for(int i=0;i<n;i++) std::cin>>a[i];
    for(int i=0;i<n;i++) std::cin>>b[i];
    int dp[2]={0,-INF};
    for(int i=0;i<n;i++){
        int new_dp[2]={-INF,-INF};
        for(int j=0;j<=1;j++){
            if(dp[j]==-INF) continue;
            for(int v1=0;v1<=1;v1++){
                if(j==1&&v1==1) continue;
                for(int vb=0;vb<=1;vb++){
                    int val=get_max_sum(b[i],a[i],v1,vb);
                    if(val!=-INF) new_dp[vb]=max(new_dp[vb],dp[j]+val);
                }
            }
        }
        dp[0]=new_dp[0];
        dp[1]=new_dp[1];
    }
    std::cout<<max(dp[0],dp[1])<<"\n";
    return 0;
}
```
