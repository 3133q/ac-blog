问题--[P3901 数列找不同 - 洛谷](https://www.luogu.com.cn/problem/P3901)

大致意思为：有一组数，询问q次，对该区间进行查询，看是否存在不同的元素

常规解法：莫队算法[普通莫队算法 - OI Wiki](https://oi-wiki.org/misc/mo-algo/)

[莫队算法——从入门到黑题 - WAMonster - 博客园](https://www.cnblogs.com/WAMonster/p/10118934.html)

巧妙思路：采用两个数组（对于输入元素，直接采用k代替）

既然求的是区间是否有重复的元素，那么可以对数组lim进行动态更新，例如--

```c++
for(int i=1;i<=n;i++){
		std::cin>>k;
		lim[i]=max(lim[i-1],a[k]+1);
		a[k]=i;
	}
```

这里a数组储存每个i的值，方便后续比对，而lim数组从前往后递推，如果能找到一样的数，那么a[k]+1就可以让他更大

```c++
for(int i=1;i<=q;i++){
		std::cin>>l>>r;
		if(lim[r]<=l) std::cout<<"Yes"<<'\n';
		else std::cout<<"No"<<'\n';
	}
```

这里是因为前面每轮先用lim数组去遍历，a数组初始为0，只要前面没有出现过这个数字，那么a数组一直都为0，然后lim数组结果也会受限制，只要出现了一次重复的数字，即可以定位到相应位置，这时将a[k]+1去对比，取更大的，就好比如下的例子中lim[4]，前面出现过2，所以更新为2+1=3，意思就是只有当l&gt;=3，才能不出现重复，继续，继续出现重复的数字，由于受前面的影响，只能继续取大的，一步步往后逼近，这就是巧妙的思路！

1 2 3 2 3

lim[1]=max(0,1)=1

a[1]=1

lim[2]=max(1,1)=1

a[2]=2;

lim[3]=max(1,1)=1

a[3]=3

lim[4]=max(1,3)=3

a[2]=4

lim[5]=max(3,4)=4

a[3]=5
