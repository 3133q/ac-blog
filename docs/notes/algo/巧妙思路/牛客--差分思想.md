# 差分思想

> 以后见到修改一个区间，或者一个区间加上/减去一个数时，都要想到差分思想，也就是动边界，而不去管内部的数字，这就是差分思想

## 2.分析

其实很清楚，就是说给出l，r表示一个区间，如果l&lt;=r，那么就把[l,r]这个区间翻转，0变为1,1变为0，反之，l&gt;r的话，就直接顺过去

这里有一个小技巧，因为s[n]=s[0]，就意味着0往左边一个是n，所以说我们在处理左边界的时候，可以直接用到%的魔法，left=(l-1+n)%n，可以发现l=0时直接处理为n-1，非常漂亮

这题我们可以考虑差分思想，因为内部序列的翻转不会影响，边界才会对下一步造成影响，所以我们想着先存储一下相邻位置是否相同，弄成一个数组，最后我们只需要维护这个数组就行了，中间的数字不用管，记为diff数组吧，表示i与i+1位是否相同，为了方便，i+1取模n

然后在区间变化中，我们只要更改边界值即可，中间的不需要动

## 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<cmath>
#include<vector>
#include<map>
#include<algorithm>
#include<climits>
#define int long long
using namespace std;
const int N=2e5+10;
int diff[N];
signed main(){
    int n,q;
    std::cin>>n>>q;
    string s;
    std::cin>>s;
    int total=0;
    for(int i=0;i<n;i++){
        if(s[i]!=s[(i+1)%n]){
            diff[i]=1;
            total++;
        }
    }
    for(int i=1;i<=q;i++){
        int l,r;
        std::cin>>l>>r;
        int left_b=(l-1+n)%n;
        int right_b=r;
        if(left_b!=right_b){
            if(diff[left_b]){
                diff[left_b]=0;
                total--;
            }
            else{
                diff[left_b]=1;
                total++;
            }
            if(diff[right_b]){
                diff[right_b]=0;
                total--;
            }
            else{
                diff[right_b]=1;
                total++;
            }
        }
        std::cout<<total<<'\n';
    }
    return 0;
}
```
