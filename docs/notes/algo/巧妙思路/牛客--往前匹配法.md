## 分析

其实很好理解，就是问原有的字符串里边能不能通过删去子串"niu"和"mo"，然后剩下的拼一起，最后把整个字符串给全删了

我们可以知道，第一种最好的情况就是全是连着的子串niumoniumo这种的，或者是通过删去一部分然后拼在一起重新构成新的子串，比如nmomoiu，mniuniuo这样的，不难看出，我们其实可以采用往前匹配大法，让o匹配m，iu匹配n，采用栈的思路（但这里可以简单点，直接使用字符串）

## 思路

首先，先执行一个字符添加至字符串的操作，然后关键点在于既然你无法确定啥时候可以删（也就是啥时候能凑齐mo或者niu），那么我们就每隔这两个数量出现的时候都判断一次，比如当s.size()&gt;=2时，我们就可以知道后边可能可以出现"mo"了，然后直接if暴力模拟，以此类推，当长度大于等于3时，有可能出现"niu"了，依旧判断。。

可以想象成只要匹配成功了的就直接pop，不影响后边的判断，其实这就是栈的思路

## 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>

    int n;

    string s1="";
    string s;
    std::cin>>s;
    int ans=0;
    for(char c:s){
        s1+=c;
        if(s1.size()>=2){
            if((s1.substr(s1.size()-2))=="mo") s1.pop_back(),s1.pop_back();
        }
        if(s1.size()>=3){
            if((s1.substr(s1.size()-3))=="niu")s1.pop_back(),s1.pop_back(),s1.pop_back();
        }
    }
    if(s1.empty()) std::cout<<"Yes";
    else std::cout<<"No";
    return 0;
}
```
