# 鸽巢原理

> 也叫抽屉原理，常用于**存在性证明**和求最坏情况的解。

## 一、基本原理

将 $n+1$ 个物品放入 $n$ 个抽屉，至少有一个抽屉含 $\ge 2$ 个物品。

> 反证法：若每个抽屉最多 $1$ 个，则最多 $n$ 个，矛盾。

---

## 二、推广

将 $n$ 个物品分为 $k$ 组，至少有一组合有 $\ge \lceil n/k \rceil$ 个物品。

---

## 三、经典例子

### 1. 生日相同

$1500$ 人中至少 $5$ 人生日相同：$\lceil 1500 / 366 \rceil = 5$

### 2. 握手次数

$n$ 个人握手，一定存在两人握手次数相同。

等价于：$n$ 个结点的无向图（无自环无重边），一定有两个结点度数相同。

分类讨论：
- 有结点度为 $0$：不存在度为 $n-1$ 的结点 → $n-1$ 个抽屉，$n$ 个鸽子 → $\lceil n/(n-1) \rceil = 2$
- 无结点度为 $0$：$n-1$ 个抽屉，$n$ 个鸽子 → 同上

---

## 四、例题一：吃糖果

> [HDU 1205](https://acm.hdu.edu.cn/showproblem.php?pid=1205)

### 题目

$K$ 种糖果，不能在相邻两次吃同一种，问是否能吃完。

### 分析

设最多的糖果数为 $N$，其余总和为 $S$。

由鸽巢原理：把 $N$ 个糖果作为"隔板"，需要至少 $N-1$ 个其他糖果来插入。

- $S \ge N - 1$ → `Yes`
- $S < N - 1$ → `No`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long LL;

void solve() {
    int K; cin >> K;
    LL N = 0, S = 0, x;
    for (int i = 1; i <= K; i++) {
        cin >> x;
        N = max(N, x);
        S += x;
    }
    S -= N;
    cout << (S >= N - 1 ? "Yes" : "No") << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    int T; cin >> T;
    while (T--) solve();
}
```

## 五、例题二：绝对值相等

### 题目

给定数组 $a[1..n]$ 和 $b[1..m]$，找到 $|a_i - a_j| = |b_k - b_l|$，其中 $a_i \neq a_j, b_k \neq b_l$。

### 分析

- 若 $a$ 或 $b$ 中有重复元素，差值 $= 0$，直接输出
- 否则排序去重后，用鸽巢原理枚举 $a_i + b_l$：
  - $0 \le a_i + b_l \le 2 \times 10^7$
  - 有 $2 \times 10^7$ 个"抽屉"，$n \times m$ 只"鸽子"
  - 当 $n \times m$ 足够大时必然有重复

```cpp
#include <bits/stdc++.h>
using namespace std;
#define rep(i, a, b) for (int i = (a); i <= (b); i++)
typedef pair<int, int> PII;

constexpr int N = 1e6 + 10, M = 1e7 + 5;
int n, m, a[N], b[N];
int posA[M], posB[M], val[M];
bool vis[2 * M];
PII mp[2 * M];

void solve() {
    cin >> n >> m;
    rep(i, 1, n) { cin >> a[i]; posA[a[i]] = i; }
    rep(i, 1, m) { cin >> b[i]; posB[b[i]] = i; }

    // 判重
    int ai = 0, aj = 0, bl = 0, bk = 0;
    rep(i, 1, n) {
        if (val[a[i]]) { ai = val[a[i]]; aj = i; break; }
        val[a[i]] = i;
    }
    fill(val, val + M, 0);
    rep(i, 1, m) {
        if (val[b[i]]) { bl = val[b[i]]; bk = i; break; }
        val[b[i]] = i;
    }
    if (ai && aj && bl && bk) {
        cout << ai << ' ' << aj << ' ' << bl << ' ' << bk;
        return;
    }

    sort(a + 1, a + n + 1); sort(b + 1, b + m + 1);
    n = unique(a + 1, a + 1 + n) - a - 1;
    m = unique(b + 1, b + 1 + m) - b - 1;

    rep(i, 1, n) rep(l, 1, m) {
        int now = a[i] + b[l];
        if (vis[now]) {
            auto [ajj, bkk] = mp[now];
            cout << posA[a[i]] << ' ' << ajj << ' ' << posB[b[l]] << ' ' << bkk;
            return;
        }
        vis[now] = true;
        mp[now] = {posA[a[i]], posB[b[l]]};
    }
    cout << -1 << '\n';
}
```

## 小结

鸽巢原理的核心：**用最坏情况的边界条件推导是否存在解**，往往能让看似复杂的组合问题迎刃而解。
