# 格雷码

> 相邻两个编码只有**一位二进制不同**的编码系统。

## 一、定义

$n$ 位格雷码序列 $G(0), G(1), \dots, G(2^n-1)$。

例如 $3$ 位：$000, 001, 011, 010, 110, 111, 101, 100$。

---

## 二、构造方法

### 1. 手动构造（生成法）

从 $0$ 开始，交替执行：

1. 翻转最低位
2. 翻转最右边 $1$ 的左邻位

重复 $2^{k-1}$ 次可得 $k$ 位格雷码。

### 2. 镜像构造

- 已有 $k-1$ 位格雷码
- 正序前加 $0$ 得前半
- 逆序前加 $1$ 得后半
- 拼接即得 $k$ 位

---

## 三、计算公式

**核心公式：**
$$
G(n) = n \oplus \left\lfloor \frac{n}{2} \right\rfloor
$$

### 代码

```cpp
int g(int n) { return n ^ (n >> 1); }
```
