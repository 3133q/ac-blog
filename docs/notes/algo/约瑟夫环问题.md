# 约瑟夫环问题

> $n$ 个人围成一圈，每报到 $k$ 的人出局，求最后幸存者的位置。

## 一、基础版本（$k = 1$）

每报一人，杀下一人，直到剩一人。

### 规律

- 当 $n = 2^a$（$2$ 的幂次）时：幸存位置为 $1$
- 当 $n = 2^a + b$ 时：幸存位置为 $2b + 1$

例如 $n = 14 = 2^3 + 6$，幸存位置为 $2 \times 6 + 1 = 13$。

---

## 二、推广版本（任意 $k$）

### 递推公式

设 $f(n, k)$ 为 $n$ 个人间隔 $k$ 的最后幸存者编号：
$$
f(n, k) = (f(n-1, k) + k) \bmod n
$$

从 $f(1,k) = 0$ 开始递推到 $n$，最终答案 $+1$。

### 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, k, r = 0;
    cin >> n >> k;
    for (int i = 1; i <= n; i++)
        r = (r + k) % i;
    cout << r + 1;
    return 0;
}
```

> 注意数据较大时取模，最终结果 $+1$。

---

## 小结

| 情况 | 解法 |
|------|------|
| $k=1$ | $n = 2^a + b \Rightarrow 2b + 1$ |
| 任意 $k$ | 递推 $f(i) = (f(i-1) + k) \bmod i$ |
