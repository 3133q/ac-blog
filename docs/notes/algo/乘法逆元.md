# 乘法逆元

> 当中间结果无法整除时，用逆元把除法转为乘法。

## 一、什么是乘法逆元

对于整数 $a$ 与模数 $b$（互质），若 $x$ 满足：
$$
ax \equiv 1 \pmod b
$$
则称 $x$ 为 $a$ 关于模 $b$ 的**乘法逆元**，代码即 `a * x % b == 1`。

### 为什么需要逆元

当 $m$ 很大时要计算 $\dfrac{m}{a} \bmod b$。若中间步骤无法整除，直接取模会出错。

设 $a$ 的逆元为 $d$，有 $m \cdot d \bmod b = \dfrac{m}{a} \bmod b$，把除化成乘。

---

## 二、方法一：扩展欧几里得

扩展欧几里得求 $ax + by = \gcd(a, b)$ 的解。

### 推导

由 $\gcd(a,b) = \gcd(b, a \bmod b)$ 和 $a \bmod b = a - \lfloor a/b \rfloor \cdot b$，展开得：
$$
x = y',\quad y = x' - \lfloor a/b \rfloor \cdot y'
$$
递归终点：$b = 0$ 时 $x = 1, y = 0$。

### 求逆元

逆元条件 $ad \equiv 1 \pmod b$ 等价于 $ad - kb = 1$，令 $x = d, y = -k$，即求 $ax + by = 1$。

```cpp
typedef long long LL;
LL ExGCD(LL a, LL b, LL &x, LL &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    LL d = ExGCD(b, a % b, x, y), t = x;
    x = y, y = t - a / b * x;
    return d;
}
int ExGcdInv(int a, int b) {
    int x, y;
    ExGCD(a, b, x, y);
    return x;
}
```

| 维度 | 说明 |
|------|------|
| 时间复杂度 | $O(\log n)$ |
| 适用范围 | 存在逆元即可求，模数大时最常用、最安全 |

## 三、方法二：费马小定理

若 $b$ 为质数且 $a$ 与 $b$ 互质：
$$
a^{b-1} \equiv 1 \pmod b
$$
即 $a \cdot a^{b-2} \equiv 1$，故 $a^{b-2}$ 即为逆元，用快速幂求解。

```cpp
int PowMod(int a, int n, int mod) {
    int ret = 1;
    while (n) {
        if (n & 1) ret = 1LL * ret * a % mod;
        a = 1LL * a * a % mod;
        n >>= 1;
    }
    return ret;
}
int FermatInv(int a, int b) {
    return PowMod(a, b - 2, b);
}
```

| 维度 | 说明 |
|------|------|
| 时间复杂度 | $O(\log b)$ |
| 适用范围 | 模数 $b$ 必须为**质数** |

---

## 四、方法三：递推

设 $k = \lfloor b/a \rfloor$，$r = b \bmod a$。由 $ak + r \equiv 0 \pmod b$ 推导：
$$
\operatorname{inv}(a) \equiv -\lfloor b/a \rfloor \cdot \operatorname{inv}(b \bmod a) \pmod b
$$

```cpp
LL Inv(LL a, LL b) {
    if (a == 1) return 1;
    return (b - b / a) * Inv(b % a, b) % b;   // b - b/a 处理负号
}
```

| 维度 | 说明 |
|------|------|
| 时间复杂度 | $O(\log b)$ |
| 适用范围 | $b$ 必须为质数，代码简单但需谨慎使用 |

---

## 五、逆元打表

基于递推，预处理 $1 \sim mod-1$ 所有逆元，适合频繁查询。

```cpp
int invList[mod + 10];
void GetInv(int mod) {
    invList[1] = 1;
    for (int i = 2; i < mod; i++)
        invList[i] = 1LL * (mod - mod / i) * invList[mod % i] % mod;
}
```

## 小结

| 方法 | 适用场景 |
|------|----------|
| 扩展欧几里得 | 通用，模数不一定是质数 |
| 费马小定理 | 模数为质数 |
| 递推 / 打表 | 多次查询不同数的逆元 |
