# 构造函数

## 问题

构造三个正整数 `x, y, z`，满足：

1/x + 1/y + 1/z = 2/n

## 构造方法

取

- x = n
- y = n + 1
- z = n(n + 1)

验证：

```
1/n + 1/(n+1) + 1/(n(n+1))
= (n+1 + n + 1) / (n(n+1))
= (2n + 2) / (n(n+1))
= 2(n+1) / (n(n+1))
= 2/n
```

## 注意

当 n = 1 时，构造结果为 x = 1, y = 2, z = 2，其中 y 与 z 相等；若题目要求三个数两两不同，则 n = 1 无解。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n;
    cin >> n;
    if (n == 1) {
        cout << "无解" << '\n'; // 视题目要求而定
    } else {
        cout << n << ' ' << n + 1 << ' ' << n * (n + 1) << '\n';
    }
    return 0;
}
```
