Dilworth定理是指对于一个偏序集，最少链划分等于最长反链长度。具体来说，如果有一个有限项的实数序列，其最长不降子列的元素个数等于将它分为若干个不交下降子列的最小个数。换句话说，这个定理提供了一种将序列划分成最少的子序列（每个子序列是递减的）的方法，这些子序列的数量等于最长不降子列的长度。这个定理在组合数学和计算机科学中都有广泛的应用，例如在解决最长上升子序列问题时非常有用。此外，Dilworth定理还有对偶的形式，即在二分图中，最大匹配等于最小点覆盖。这个定理与网络流的最大流最小割定理有相似之处，因为它们都提供了一种通过图论来解决极值问题的方法。

即：我们现在要把这个序列划分成最少数量的不上升子序列，那么我们只需要反过来求最长上升子序列的长度。

注意`lower_bound`是查找第一个大于等于某值的元素，如果是求最长不下降子序列，我们需要用到`upper_bound`，查找第一个大于某值的元素。（因为最长不下降子序列允许把3-&gt;4替换成3-&gt;3）

```cpp
*lower_bound(dp + 1, dp + len + 1, A[i], greater<int>()) = A[i];
```
