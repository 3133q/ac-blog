# 数学规律题

> 不依赖经典算法的题目，需要发现**变量之间的数学规律**直接求解。

## 一、题型特点

当题目给出变量范围后，可以**直接推导出计算式**，无需 BFS/DFS 或 DP。

---

## 二、例题一：棋盘象的移动

> [牛客周赛 Round 122 B](https://ac.nowcoder.com/acm/contest/125083/B)

### 题目

$n \times m$ 棋盘，在任意位置放一个"象"，跳任意步。求最优策略下最多能到达多少个不同位置。

（此"象"的走法不是传统田字，而是按题目描述移动）

### 分析

- 从 $(1,1)$ 开始试跳，发现可达点的坐标满足规律：
  - $(4k_1+1, 4k_2+1)$
  - $(4k_1+3, 4k_2+3)$
- 直接计数即可

### 公式

第一类点数：$\left(\lfloor \frac{n-1}{4} \rfloor + 1\right) \times \left(\lfloor \frac{m-1}{4} \rfloor + 1\right)$

第二类点数：$\left(\lfloor \frac{n-3}{4} \rfloor + 1\right) \times \left(\lfloor \frac{m-3}{4} \rfloor + 1\right)$

结果 = 两类之和

### 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    long long n, m;
    for (int i = 0; i < t; i++) {
        cin >> n >> m;
        if (m <= 2 || n <= 2) {
            cout << 1 << '\n';
            continue;
        }
        cout << ((n - 1) / 4 + 1) * ((m - 1) / 4 + 1)
              + ((n - 3) / 4 + 1) * ((m - 3) / 4 + 1) << '\n';
    }
    return 0;
}
```

## 三、例题二：极差最大化

> [P8480 「HGOI-1」PMTD](https://www.luogu.com.cn/problem/P8480)

### 题目

长度为 $n$ 的整数序列，每次可选择一数进行 $+2$、$-2$、$\times 2$、$/2$ 之一，操作 $m$ 次后求最大极差。

### 分析

- 只需对最大值进行操作
- 比较 $\times 2$ 和 $+2$：$2x > x+2$ 当 $x > 1$
- 当 $x \le 1$ 时用 $+2$，否则用 $\times 2$

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m;
    cin >> n >> m;
    vector<long long> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    while (m--) {
        if (a[n] <= 1) a[n] += 2;
        else a[n] *= 2;
    }
    cout << a[n] - a[1];
    return 0;
}
```

## 小结

这类题的核心：**观察小规模数据 → 找规律 → 推广公式 → 直接计算**，不要被惯用的搜索/DP 思路束缚。
