1LL的用法

当一个int类型的数据需要进行一个运算 100000*100000/1000，虽然最后算出的结果不超过int（只有16位编译器的unsigned int 是65535，现在是4294967295），但是在运算的过程里（进行除法之前）超过了int类型的范围，这时候我们就需要强制类型转换来消除错误，但一直强制转换会有些麻烦，这个时候用1LL就方便了。

```c++
#include <stdio.h>
#include <stdlib.h>
 
int main()
{
    int a = 1LL * 100000 * 100000 / 1000;
    printf("%d", a);
    system("pause");
    return 0;
}
```
