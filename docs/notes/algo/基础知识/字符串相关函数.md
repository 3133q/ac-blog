c++

string s     ----创建空字符串

string s1("aa"); string s2(s1);    ----拷贝构造函数，用s1对s2进行初始化

s.pop_back()  ----删除最后一个字符

s.rfind(str)  ----从末尾开始找子串str

s.replace(pos,len,str)  ----从位置pos开始，替换len个字符为str

s.substr(pos,len)  ----从位置pos开始，截取len个字符（len省略时，取到末尾）

s.substr(pos)   ---相当于从pos位置开始，一直截取到最后一个字符

s.substr()   ---截取全部字符

s.size()  ----计算长度

s.capcity()  ----返回当前分配的内存可容纳的字符数

s.empty() ----判断是否为空，长度为0返回1

扩展：将整数转换为字符串的方法     

(c++)      `std::to_string(i)`   

(c)           `sprintf(char *str,const char *format,.....)`

解释----str表示写入字符串的指针，format格式化字符串，指定了如何格式化后续参数

eg.   

```c
#include <stdio.h>
int main() {
    char str[20];
    int num = 12345;
    sprintf(str, "%d", num);
    printf("转换后的字符串: %s\n", str);
    return 0;
}       
```

但是sprintf不检查缓冲区的长度，很容易造成溢出，可以采用snprintf

eg.  

```c
#include <stdio.h>
int main() {
    char str[10];
    int num = 12345678;
    
    snprintf(str, sizeof(str), "%d", num);
    
    printf("转换后的字符串: %s\n", str);
    
    return 0;
}
```

将字符串转换为数字的方法   

(c++)

- `stoi()`：将字符串转换为整数（int 类型），适用于 C++11 及以上版本。
- `stol()`：将字符串转换为长整型（long 类型）。
- `stof()`：将字符串转换为浮点型

示例

```c++
std::string str = "123";
int num = std::stoi(str);
```

​        `stringstream`  字符串转为数字

示例

```c++
std::stringstream ss;
ss << "456";
int num;
ss >> num;
```

(c)

- `atoi()`：将字符串转换为整数（int 类型）。
- `atol()`：将字符串转换为长整型（long 类型）。
- `atof()`：将字符串转换为浮点数（double 类型）。

示例

```c
#include <stdio.h>
#include <stdlib.h>
int main() {
    char str1[] = "123";
    char str2[] = "  -456abc";
    char str3[] = "789.123";
    int num1 = atoi(str1);
    int num2 = atoi(str2);
    int num3 = atoi(str3);
    printf("str1 转换结果：%d\n", num1);
    printf("str2 转换结果：%d\n", num2);
    printf("str3 转换结果：%d\n", num3);
    return 0;
}
```
