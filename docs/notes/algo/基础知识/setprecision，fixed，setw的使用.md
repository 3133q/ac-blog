# setprecision，fixed，setw的使用

## 引入

```c++
//类型一：整数位很多
double x=12345678;
//类型二：小数位很多，有效小数位少
double y=0.00001234;
//类型三：小数位很多，有效小数位也多
double z=3.1415926;

cout<<x<<endl;
cout<<y<<endl;
cout<<z<<endl;
```

当进行这样的输出时，结果会是

```c++
1.23457e+07
1.234e-05
3.14159
```

采用了科学计数法

如果改为整型呢？

```c++
double x=12345678;
cout<<x<<endl;
```

结果。。。

```c++
1.23457e+07
```

## 介绍

对于单纯的cout输出法，特点如下：

保留的有效位至多6位，若不满则会四舍五入

删去无效的位数，比如2.0输出2

适当情况会使用科学计数法，12345678 输出 1.23457e+07

**特殊**：

```c++
double x=1.234595;
cout<<x<<endl;
```

结果是

```c++
1.2346
```

解释：先截取6位，下一位要四舍五入，而下一位是5，要进位，**而上一位恰恰是9，9+1=10，要再往前一位加一**，即4要加一，本应该输出1.23460，**但是末尾的0不算是有效数位**，根据规则二（本规则）要删去，即输出1.2346这个有效数位5位的数啦！！

那我们该如何避免科学计数法呢？？？

## fixed

可以避免科学计数法，直接输出。。。

```c++
//类型一：整数位很多
double x=12345678;
//类型二：小数位很多，有效小数位少
double y=0.00001234;

cout<<fixed<<x<<endl;
cout<<fixed<<y<<endl;
```

结果

```c++
12345678.000000
0.000012
```

还有还有，如果确定精度呢？？？

## setprecision

相信大家都知道，**fixed与setprecision(n)连用可以控制小数点后的位数**，现在就可以理解因为那是定点数记数法。

***如果没有fixed的话，就是浮点数记数法了，那么它控制的应该就是有效数字的位数（包括小数点前的）！！！！！***

// 设置精度为 5

std::cout &lt;&lt; std::setprecision(5) &lt;&lt; pi &lt;&lt; '\n'; // 输出: 3.1416

// 设置精度为 9

std::cout &lt;&lt; std::setprecision(9) &lt;&lt; pi &lt;&lt; '\n'; // 输出: 3.14159265

## setw

若想用setw(int n)呢，要加头文件 [iomanip&gt;[io+manipulator的意思]
其控制后面输出的长度，默认右对齐，输出内容长度不够用空格补齐，输出内容长度超过则正常输出。
**注：1. setw()只对后面紧跟的输出有限制。
\2. 标点符号占一位！**

```c++
	double x = 0.1;
	double y = 0.123456;

	cout  <<setw(7)<< x << endl;
	cout << x << endl;
	cout << setw(3)<<y << endl;
```

结果

```c++
    0.1
0.1
0.123456
```
