计数排序

计数排序的思路大致可以描述为：统计数组中每个数字出现的次数，然后依据前缀和算法算出每个数应该填入的位置，然后直接填充即可，下面用直观的图解来讲述

![img](https://img2022.cnblogs.com/blog/3039354/202211/3039354-20221121001350275-321284273.png)

像这样，先用一个新数组存下原数组每个数字出现的次数

![img](https://img2022.cnblogs.com/blog/3039354/202211/3039354-20221121001403556-434622299.png)

然后按位置存放即可

*时间复杂度*

计数排序时间复杂度为 ***O(n + k)***，其中 ***n*** 为数据元素个数， ***k*** 为数据元素范围大小。
当数据范围大小 ***k*** 恰好和 ***n*** 相等时，时间复杂度为 ***O(n)***。

代码：

```c++
#include<bits/stdc++.h>
using namespace std;
int cnt[10010],b[1001];
int* count(int *a,int n,int w){
	memset(cnt,0,sizeof(cnt));
	for(int i=0;i<n;i++) cnt[a[i]]++;
	for(int i=1;i<=w;i++) cnt[i]+=cnt[i-1];
	for(int i=n-1;i>=0;i--) b[--cnt[a[i]]]=a[i];
	return b;
}
int main(){
	int a[1010],n,w,maxx=-1e5+2;
	scanf("%d",&n);
	for(int i=0;i<n;i++) {
		scanf("%d",&a[i]);
		if(a[i]>=maxx) maxx=a[i];
	}
	int *p=count(a,n,maxx);
	for(int i=0;i<n;i++) printf("%d ",p[i]);
	//for(int i=0;i<n;i++) printf("%d ",a[i]);
	return 0;
}
```
