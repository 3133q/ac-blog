基数排序

基数排序可以说是桶排序的进阶版，桶排序我们知道是按照10个数为一组，放到一个桶里，然后对每个桶做排序，那么，基数排序其实是按照位数，从个位开始，进行分组，比如0-9,10分到0组，58分到8组，以此类推，然后个位排完排十位，因为单纯排一位肯定保证不了大小，所以得一直顺延知道所有位数都排完，下面开始图解

## 时间复杂度

基数排序的时间复杂度取决于当前最大元素的最高位，若最大元素的最高位大小为 ***digit***，共有 ***n*** 个元素，我们对每一位数字都要进行 ***n*** 次遍历。故时间复杂度为 ***O(n×digit)***。

## 局限性

因为要计算每一位数字，所以基数排序只适用于元素都是**整数**的情况。🙄

下面给出代码：

```c++
#include<bits/stdc++.h>
using namespace std;
void msd(int *a,int n,int w){
	int base=1,d=0;
	int cnt[10],tmp[n];
	memset(cnt,0,sizeof(cnt));
	while(w){
		w/=10;
		d++;
	}
	for(int j=0;j<d;j++){
		for(int i=0;i<10;i++) cnt[i]=0;
		for(int i=0;i<n;i++) cnt[(a[i]/base)%10]++;
		for(int i=1;i<10;i++) cnt[i]+=cnt[i-1];
		for(int i=n-1;i>=0;i--) tmp[--cnt[(a[i]/base)%10]]=a[i];
		for(int i=0;i<n;i++) a[i]=tmp[i];
		base*=10;
	} 
}
int main(){
	int n,a[3001],maxx=-1e5+2;
	scanf("%d",&n);
	for(int i=0;i<n;i++)  scanf("%d",&a[i]);
	for(int i=0;i<n;i++) if(a[i]>maxx) maxx=a[i];
	msd(a,n,maxx);
	for(int i=0;i<n;i++) printf("%d ",a[i]);
	return 0;
}
```

使用base来完成位数的前推。。。
