模2的幂

一个数对2的非负整数次幂取模，等价于取二进制下一个数的后若干位，等价于和mod-1进行与操作，于是可以知道，2的非负整数次幂对它本身取模，结果为0，即如果是2的非负整数次幂，n和n-1与操作为0

事实上，对于一个正整数n，n-1会将n的最低位置零，并将后续位数全部置一，因此n和n-1的与操作等价于删掉n的最低一位，借此可以判断一个数是否为2的非负整数次幂，当且仅当n的二进制表示只有一个1时，满足

```c++
bool isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }
```
