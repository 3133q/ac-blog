# 素数筛选

## 一.埃氏筛

本质上就是利用当前找到的小素数，比如2,3这些小的数字，然后进一步去推他们的倍数，也就是把他们的倍数全部删去，因为都会是合数，也就是一轮轮删（打好标记）

具体代码见Era(n)函数

## 二.线性筛

本质上进行了优化，因为即便将埃氏筛优化为i*i开始，每轮增量为i，还是会出现一个数字经过多轮的重复标记，不好合适，所以需要采用线性筛，也就是质因数去筛，如果当前已经有了2,3这些质因子，那就去删掉存在这些质因子的大数，随后便可以标记

具体代码见sieve(n)函数



## 代码

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N=1e5+2;
int prime[N],vis[N];
bool isprime(int n){
	if(n==1) return 0;
	if(n==2||n==3) return 1;
	double p=sqrt(n);
	for(int i=2;i<=p;i++){
		if(n%i==0) return 0;
	}
	return 1;
}
void Era(int n){
	memset(prime,0,sizeof(prime));
	vis[1]=1;
	int total=0;
	for(int i=2;i<=n/2;i++){
		if(!vis[i]){
			prime[++total]=i;
			for(int j=i*i;j<=n;j+=i){
				vis[j]=1;
			}
		}
	}
}
void sieve(int n){
	memset(prime,0,sizeof(prime));
	vis[1]=1;
	int total=0;
	for(int i=2;i<=n;i++){
		if(!vis[i]) prime[++total]=i;
		for(int j=1;i*prime[j]<=n;j++){
			vis[i*prime[j]]=1;
			if(i%prime[j]==0) break;
		}
	}
}
signed main(){
	int n;
	std::cin>>n;
	//Era(n);
	sieve(n);
	for(int i=1;i<=n;i++){
		if(!vis[i]) std::cout<<i<<" ";
	}
	return 0;
}
```
