# 位运算

## 巧用

设置某一位为1： x|=(1&lt;&lt;i)

设置某一位为0： x&=~(1&lt;&lt;i)

翻转某一位： x^=(1&lt;&lt;i)

检查某一位是不是1： if(x&(1&lt;&lt;i))

## lowbit

lowbit(x) 即 x 二进制最右边的一个 1 连带着它后面的 0 组成的值，比如 12（1100）的 lowbit 是 4（100）。

实现就一行，利用了补码的性质：

```cpp
int lowbit(int x){
	return x&-x;
}
```

一个数取负数会先反码再加一，这样正好能定位到最末尾的一个 1。树状数组里跳来跳去靠的就是它，详见[树状数组](../fenwick-tree)

## 内置函数

gcc 提供了几个很好用的位运算函数，注意后缀带 ll 的版本才支持 long long：

```cpp
__builtin_popcount(x)   //统计x二进制中1的个数
__builtin_clz(x)        //统计x前导0的个数（x不能为0）
__builtin_ctz(x)        //统计x末尾0的个数，即lowbit是2的几次方（x不能为0）
```

顺便一提，`31-__builtin_clz(n)` 可以快速求出 $\lfloor \log_2 n \rfloor$，比循环快多了。

## 判断 2 的幂

x 是 2 的幂，当且仅当二进制里只有一个 1，那么 x-1 就会把这个 1 变成 0 后面全变成 1，两者与起来正好是 0：

```cpp
if(x>0&&(x&(x-1))==0) //x是2的幂
```

## 状压枚举

用一个整数的二进制位表示选或不选，就是状压的核心思想，详见[二进制集合操作](./二进制集合操作)

### 枚举全集的子集

```cpp
for(int s=(1<<n)-1;s;s=(s-1)&mask)
```

(s-1)&mask 的效果就是找到比 s 小的下一个子集，总复杂度是 $O(3^n)$，而不是暴力的 $O(4^n)$

### 枚举某集合内的所有子集

```cpp
for(int s=mask;s;s=(s-1)&mask)
```

### 常用操作速查

| 操作 | 写法 |
| --- | --- |
| 加入元素 i | `s \|= (1<<i)` |
| 删除元素 i | `s &= ~(1<<i)` |
| 判断是否有元素 i | `s & (1<<i)` |
| 集合大小 | `__builtin_popcount(s)` |
| 取交集 | `a & b` |
| 取并集 | `a \| b` |
| 全集 | `(1<<n)-1` |
