离散化

离散化是一种数据处理的技巧，本质上是一种哈希。

适用于那些数据因为本身的原因，无法用原数据下标进行操作，但影响因素只有元素间的相对大小关系，这时便可以使用离散化

将一个数组离散化是常见的处理方法。

数组中可能会有重复的元素，一般把相同的元素离散化为相同的数据

1.创建原数组的副本

2.将副本中的值从小到大排序

3.将排序好的副本去重

4.查找原数组每一个元素在副本中的位置，位置即为排名，作为离散化后的值

代码如下：

```c++
// arr[i] 为初始数组,下标范围为 [1, n]
for (int i = 1; i <= n; ++i)  // step 1
  tmp[i] = arr[i];
std::sort(tmp + 1, tmp + n + 1);                          // step 2
int len = std::unique(tmp + 1, tmp + n + 1) - (tmp + 1);  // step 3
for (int i = 1; i <= n; ++i)                              // step 4
  arr[i] = std::lower_bound(tmp + 1, tmp + len + 1, arr[i]) - tmp;
```

unique的作用即为去重。

对于vector也同样适用

```c++
// std::vector<int> arr;
std::vector<int> tmp(arr);  // tmp 是 arr 的一个副本
std::sort(tmp.begin(), tmp.end());
tmp.erase(std::unique(tmp.begin(), tmp.end()), tmp.end());
for (int i = 0; i < n; ++i)
  arr[i] = std::lower_bound(tmp.begin(), tmp.end(), arr[i]) - tmp.begin();
```

举个例子 对于tmp={1,1,2,2,2,3,4,4,5}

// 第一步：std::unique(tmp.begin(), tmp.end())
// 重新排列元素，返回指向去重后末尾的迭代器
// tmp变为: {1, 2, 3, 4, 5, 3, 4, 4, 5}  // 后部分是"垃圾"数据
//          ↑           ↑
//         begin       unique返回的迭代器

// 第二步：tmp.erase(unique返回的迭代器, tmp.end())
// 删除从unique返回位置到end的所有元素
// 最终tmp: {1, 2, 3, 4, 5}
