# 三色旗问题

## 描述

给出一组只有0,1,2三个数字的序列，要求按照0 1 2的顺序，将数组重新排列

## 想法

### 一

最普通的方法，直接排序，0 1 2的顺序直接排就行

如果不是的话，也可以通过更改cmp函数，然后排序。

### 二

开一个新数组，然后遇到0，就从头开始填进去，如果遇到2，就从尾开始填，遇到1则先不处理，等到0,2填完了再把空余位置填上1

### 三

采用计数的方法，先遍历一遍数组，记下0,1,2三个数字分别出现几次，然后按0 1 2的顺序把对应数量的数字填进去就可以了

### 四

采用三指针，cur，l，r三个指针，cur，l开始指向头，r指向尾，然后如果遇到2，就把他跟尾指针对应元素互换，对应r--，因为不知道换过来的是0还是1，所以前两个指针不动；如果遇到1，则先把cur++；遇到0的话，将cur，l对应元素交换，然后他俩都++，因为1的时候我已经把cur++了，当时没有动l，所以1最终会不断移动到中间的位置

#### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<climits>
using namespace std;
int main(){
	int n,a[5001];
	std::cin>>n;
	for(int i=1;i<=n;i++) std::cin>>a[i];
	int cur=1,l=1,r=n;
	while(cur<=r){
		if(a[cur]==2){
			swap(a[cur],a[r]);
			r--;
		}
		else if(a[cur]==1) cur++;
		else {
			swap(a[cur],a[l]);
			cur++;
			l++;
		}
	}
	for(int i=1;i<=n;i++) std::cout<<a[i]<<" "; 
	return 0;
}
```
