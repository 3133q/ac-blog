# 双指针经典

## 一.盛最多水的容器

### 1.题目描述

![image-20260717164306272](/images/image-20260717164306272.png)

### 2.分析

核心公式：面积=min(height[l],height[r])*(r-l)

也就是木桶效应，能盛多少水取决于木桶短的那一边的高度，所以，知道了这个，我们就可以使用双指针了，因为普通暴力做法O(n^2)肯定超时

一开始l=0，r=n-1，宽度最大，然后去比较height[l]和height[r]，如果左侧更小，意思是现在高度被左侧限制了，我如果去缩小范围，也就是宽度变小，如果你还想要更多的容量，那只能提升高板，也就是l++，否则，r--

### 3.代码

```c++
#include <vector>
#include <algorithm>
using namespace std;
int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int max_area = 0;
    while (left < right) {
        // 计算当前面积
        int current_area=min(height[left],height[right])*(right -left);
        max_area = max(max_area, current_area);
        // 贪心策略：移动较短的一边
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }
    return max_area;
}
```

## 二.接雨水

### 1.题目描述

![image-20260717164729296](/images/image-20260717164729296.png)

### 2.分析

我们不直接合起来看，我们直接一个个坑去看，对于第i根柱子，它能接的水取决于左边最高的山峰和右边最高的山峰，存水量=max(0,min(左边最高，右边最高)-当前柱子高度)

一样，使用双指针去做这道题，维护两个变量left_max，right_max

某一时刻，如果left_max&lt;right_max，即为左侧最高比右侧的还小，那直接就说明了最小值取的是left_max，所以高度直接用left_max-h[l]，然后l++

反之，如果left_max&gt;right_max，即为右边的柱子高度更小，直接计算右侧的高度，然后r--

### 3.代码

```c++
#include <vector>
#include <algorithm>
using namespace std;

int trap(vector<int>& height) {
    if (height.empty()) return 0;

    int left = 0, right = height.size() - 1;
    int left_max = 0, right_max = 0;
    int water = 0;

    while (left < right) {
        // 更新两边的最高峰
        left_max = max(left_max, height[left]);
        right_max = max(right_max, height[right]);

        // 哪边的最高峰矮，就结算哪边的水量（因为它被对面的高峰挡住了，水流不出去）
        if (left_max < right_max) {
            // 左边是短板，结算左边当前柱子能存的水
            water += left_max - height[left];
            left++;
        } else {
            // 右边是短板，结算右边当前柱子能存的水
            water += right_max - height[right];
            right--;
        }
    }
    return water;
}
```
