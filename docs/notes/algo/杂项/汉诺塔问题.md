汉诺塔问题

问题描述：有三个立柱在地面上，给这三个立柱命名为A，B，C，开始时立柱A上有n个圆盘，大小不一，并且按从小到大的顺序依次摆放在立柱A上。现在要将立柱A上的n个圆盘移动到立柱C上，每次只允许移动一个圆盘，在移动过程中保持大盘在下，小盘在上。下面开始模拟过程（从4个开始）

![img](https://c.biancheng.net/uploads/allimg/250522/2-2505221612054T.gif)

首先，将a,b两个圆盘移动到C上，移动过程借助立柱B，移动顺序为：a-&gt;B b-&gt;C a-&gt;C

![img](https://c.biancheng.net/uploads/allimg/250522/2-25052216121TK.gif)

接下来把a,b,c这三个圆盘移动到B上，移动顺序是：c-&gt;B a-&gt;A b-&gt;B a-&gt;B

![img](https://c.biancheng.net/uploads/allimg/250522/2-250522161230191.gif)

最后，将4个圆盘都移动到立柱C上，移动顺序是：d-&gt;C a-&gt;C b-&gt;A a-&gt;A c-&gt;C a-&gt;B b-&gt;C a-&gt;C

先来总结一下移动规律：

- 将 2 个圆盘移动到指定立柱，需要移动 3 次。例如，将 a、b 圆盘由立柱 A 移到立柱 C 上，移动顺序为 a-&gt;B，b-&gt;C，a-&gt;C。
- 将 3 个圆盘移动到指定立柱，需要移动 7 次。例如，将 a、b、c 圆盘由立柱 A 移到立柱 B 上，移动顺序为 a-&gt;B，b-&gt;C，a-&gt;C，c-&gt;B，a-&gt;A，b-&gt;B，a-&gt;B。其中，前 3 次重复的是将 2 个圆盘移动到指定立柱的操作，后 4 次是将第 3 个圆盘移动到指定立柱的操作。
- 将 4 个圆盘移动到指定立柱，需要移动 15 次。同样，前 7 次重复的是将 3 个圆盘移动到指定立柱的操作，后 8 次是将第 4 个圆盘移动到指定立柱的操作。

以此类推，有n个圆盘时，移动到指定立柱，需要2^n-1次

继续思考，移动过程中，如果将 a、b、c 这 3 个圆盘看成一个整体，则移动 4 个圆盘的过程和移动 2 个圆盘一样。同理，将 a、b 2 个圆盘看成一个整体，则移动 3 个圆盘的过程也像是在移动 2 个圆盘。因此，可以使用递归的思路解决 n 个圆盘的移动问题，整个移动过程分为 3 步：

- 把立柱 A 上的 n-1 个圆盘移动到立柱 B 上；
- 把立柱 A 上的 1 个圆盘移动到立柱 C 上；
- 把立柱 B 上的 n-1 个圆盘移动到立柱 C 上。

接着，就可以使用递归直接解决啦

```c++
#include<bits/stdc++.h>
using namespace std;
void hanio(int n,char a,char b,char c){
	if(n==1) {printf("%c-->%c\t",a,c);return ;}
	else{
		hanio(n-1,a,c,b);
		printf("%c-->%c\t",a,c);
		putchar(10);
		hanio(n-1,b,a,c);
	}
}
int main(){
	int n;
	scanf("%d",&n);
	char a,b,c;
	a='A',b='B',c='C';
	hanio(n,a,b,c);
	return 0;
}
```
