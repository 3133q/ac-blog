# 记忆化搜索

> 注：这是在dp之前，对搜索进行的一个优化，来应对某些需要剪枝的题目。。。

## 概念

所谓记忆化搜索，就相当于在搜索的过程中，需要随时进行标记，哪种情况我是前面已经搜索过的，然后记住，得把前面的结果存储下来，后边发现搜索过的，直接返回答案，省去大量过程，这也正是记忆化搜索达到效果的方法

## 例题

[P1464 [PacNW 1999\] Function - 洛谷](https://www.luogu.com.cn/problem/P1464)

### 题目描述

![image-20260424154717059](/images/image-20260424154717059.png)

研读题目，很简单，不就是递归吗，但这里要注意，单纯的递归的话，对于这道题所给出的计算公式，将会进行非常多次，很容易造成TLE！！！所以就需要剪枝--记忆化搜索

从代码分析吧

### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<cmath>
#include<climits>
#include<vector>
#include<map>
#define int long long
using namespace std;
int w[21][21][21],v[21][21][21];
int ww(int a,int b,int c){
    if(a<=0||b<=0||c<=0) return 1;
    if(a>20||b>20||c>20) return ww(20,20,20);
	if(v[a][b][c]) return w[a][b][c];
	if(a<b&&b<c) w[a][b][c]=ww(a,b,c-1)+ww(a,b-1,c-1)-ww(a,b-1,c);
	else w[a][b][c]=ww(a-1,b,c)+ww(a-1,b-1,c)+ww(a-1,b,c-1)-ww(a-1,b-1,c-1);
	v[a][b][c]=1;
	return w[a][b][c];
}
signed main(){
	int a,b,c;
	while(std::cin>>a>>b>>c){
		if(a==-1&&b==-1&&c==-1) break;
		std::cout<<"w("<<a<<", "<<b<<", "<<c<<") "<<"= "<<ww(a,b,c)<<'\n';
	}
	return 0;
}
```

### 分析

首先是维度，三维，而又因为只要a,b,c其中一个大于20了，就返回的是w(20,20,20)，也就是说20之后的操作全部用之前的就OK了，开个21足矣，当然，开大点也行

然后，对于每一步，先是v数组记忆，以免重复计算，然后记录当前的值，方便后续直接采用
