十进制转二进制的通用方法（也适用于负数）

转二进制，通常来说，我们都会采用老方法，直接除2，例如对于8

8/2=4 .....0

4/2=2 .....0

2/2=1 .....0

1/2=0 .....1

然后逆序即可 8的二进制为1000

但是如果是负数呢？负数在计算机的表示就不太一样 。。。。

先讲讲负数在计算机里如何表示，先说几个概念：

1. 原码：一个十进制数，按照绝对值转换成的二进制数，称为原码
2. 反码：对于负数而言，将二级制数按位取反，所得的二进制数就是反码
3. 补码：对于负数而言，反码加1即为补码

注意，这里说对于负数而言，是因为正数的反码和补码都等于原码，不作区分，所谓引入反码和补码的目的，就是为了理解计算机里是如何进行数的加减运算的，负数在计算机里其实是通过补码存储的

举个例子吧，对于-5 由于5的二进制是 00000101（这里只写了8位，实则计算机里有32位和64位之分），第一位是符号位，0表示正，1表示负，-5的原码10000101，所以-5的反码11111010，-5的补码11111011

注意：如果末位是1，加1后要进位

好了，了解如何计算后，给出通用于负数和正数的转二进制的思路

既然直接除2行不通，那就只好直接填0 1了

以flag=1作为“移位神器” 去判断每一位是否为1，并不断让flag左移，那啥时候退出呢？？？

这里很巧妙，可以采用无符号整型数据unsigned int，占32个字节（由编辑器决定），但unsigned int类型的变量a溢出时，它会直接变成0，这也就是设计while退出条件的关键

给出代码：

```c++
#include <iostream>
#include <vector>

using namespace std;

void Ten2Two(int num)
{
    vector<int> temp;
    unsigned int flag = 1;
    while (flag)
    {
        if (num & flag) //********精髓：与每一位进行“与”操作
        {
            temp.push_back(1);
        }
        else
        {
            temp.push_back(0);
        }
        flag = flag << 1; // flag 始终只有一位是1，只有当前位是1时，num & flag才为真
    }

    for (int i = temp.size() - 1; i >= 0; i--)
        cout << temp[i];
}

int main()
{
    int num = -8;
    Ten2Two(num);
    system("pause");
    return 0;
}

```
