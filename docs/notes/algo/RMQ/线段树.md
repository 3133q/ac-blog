那么如何把子节点的信息传到父节点上呢？

采用pushup的操作

```c++
void pushup(int x){
    tr[x].sum=tr[x*2].sum+tr[x*2+1].sum;
}
```

这个操作的意思就是：节点表示的区间和等于两个子节点所表示的区间之和。即下图：



![img](https://pic1.zhimg.com/v2-4366d4d3cb495ac792474d0f7d45d58e_1440w.jpg)

有了这个操作，我们就可以递归的求出每一个节点所表示的信息。



![img](https://pica.zhimg.com/v2-203138a595486ceb129bdadab22afdda_1440w.jpg)

这个建立线段树的过程可以看作是预处理信息，把数组的信息转移到线段树的叶子节点上，

建树代码如下----

```c++
void build(int x,int l,int r){
    tr[x].l=l,tr[x].r=r;//节点表示区间的左右界
    if(l==r){
        //若l=r，说明这个节点是叶子节点，直接赋值
        tr[x].sum=a[l];//a是原数列
        return;
    }
    int mid=(l+r)/2;//mid表示左右子区间的间隔
    build(x*2,l,mid),build(x*2+1,mid+1,r);//递归建树
    //线段树是完全二叉树，左右子节点可以用x*2,x*2+1表示
    tr[x].sum=tr[x*2].sum+tr[x*2+1].sum;//pushup操作
}
```

代码实现：

```c++
int query(int x,int l,int r){
    //区间查询
    if(tr[x].l>=l&&tr[x].r<=r) return tr[x].sum;//如果该节点的区间被要查找的区间包括了，那么就不用继续找了，直接返回改节点的值就行了
    int mid=(tr[x].l+tr[x].r)/2;
    int sum=0;
    if(l<=mid) sum+=query(x*2,l,r);//如果当前节点在要查找区间左边界的右面，那么递归查找左子树
    if(r>mid) sum+=query(x*2+1,l,r);//如果当前节点在要查找区间右边界的左面，那么递归查找右子树
    return sum;//由此得出了该区间的值，返回即可
}
```

对于线段树存储空间，这里得开4*n，具体原因

//**

线段树是一种非常高效的数据结构，用于处理区间或线段上的查询和更新问题。在实现线段树时，通常需要开辟一定的空间来存储树的节点。那么，为什么线段树需要开辟的空间是原始数据大小的4倍呢？

首先，线段树虽然不一定是满二叉树或完全二叉树，但它一定是一棵平衡二叉树。这意味着可以使用数组来表示线段树，将其视为满二叉树。在满二叉树中，如果树的高度为h，那么树的节点总数大约是最后一层节点数的两倍。因此，如果区间中有n个元素，那么线段树的节点总数大约是2n。

然而，当区间元素个数不是2的幂时，线段树不是满二叉树。为了利用满二叉树的性质，可以通过添加虚拟节点的方式，将线段树构造成满二叉树。这样做的结果是，最后一层可能会有很多不存在的叶子节点。如果区间元素个数稍微超过2的幂，比如n=2^k+1，就需要额外的一层来存储这些额外的元素。这意味着，除了原有的2n个节点外，还需要额外的2n个节点来存储这些虚拟节点，总共需要4n个节点。

因此，为了确保在任何情况下都有足够的空间来表示线段树，通常会开辟4倍于区间元素个数的空间。这样可以保证无论区间元素个数是多少，都可以构造出一个完整的线段树，而不会因为空间不足而出现问题。

在实际编码中，如果线段树的根节点编号为root，那么其左孩子的编号为root*2，右孩子的编号为root*2+1。这种性质也是构造线段树需要多开空间的原因之一。通过这种方式，可以确保每个节点都有足够的空间来存储其子节点的信息，从而使线段树的操作更加高效和稳定。

综上所述，线段树需要开辟4倍空间的原因主要是为了保证在构造满二叉树时有足够的空间来存储所有的节点，包括那些虚拟节点，以及确保每个节点都能正确地存储其子节点的信息。这样做可以使线段树的实现更加简单和高效，也便于进行区间查询和更新操作。

线段树模板：

```c++
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll n,m,p,q,t;
const int N=1e7+2;
vector<int>a;
struct node{
	int sum,l,r;
}tree[4*N];
inline void pushup(int x){
	tree[x].sum=tree[2*x].sum+tree[2*x+1].sum;
}
void build(int x,int l,int r){
	tree[x].l=l,tree[x].r=r;
	if(l==r){
		tree[x].sum=a[l];
		return ;
	}
	int mid=l+((r-l)>>1);
	build(2*x,l,mid);
	build(2*x+1,mid+1,r);
	pushup(x);
}
int query(int x,int l,int r){
	if(tree[x].l>=l&&tree[x].r<=r) return tree[x].sum;
	int mid=tree[x].l+((tree[x].r-tree[x].l)>>1);
	int s=0;
	if(l<=mid) s+=query(2*x,l,r);
	if(r>mid) s+=query(2*x+1,l,r);
	return s;
}
void change(int now,int x,int k){
	if(tree[now].l==tree[now].r){
		tree[now].sum+=k;
		return ;
	} 
	int mid=tree[now].l+((tree[now].r-tree[now].l)>>1);
	if(x<=mid) change(2*now,x,k);
	else change(2*now+1,x,k);
	pushup(now);
}
int main(){
	std::cin>>n>>m;
	a.resize(n+1);
	for(int i=1;i<=n;i++) std::cin>>a[i];
	build(1,1,n);
	while(m--){
		std::cin>>p>>q>>t;
		if(p==1) change(1,q,t);
		else std::cout<<query(1,q,t)<<'\n';
	}
	return 0;
}
```
