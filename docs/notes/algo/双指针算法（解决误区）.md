双指针算法（解决误区）

双指针算法诞生的目的在于解决O(n*n)的时间复杂度，达成优化的效果，所以在使用这个算法的时候，不可当成双重for循环一样处理，不然根本就没有用到核心！！！

很容易就发现了，如果使用头尾双指针的方法去遍历判断，就必须得归位其中一个指针，归位指针不就相当于双重for循环里的从头遍历吗qwq，当时还想半天不知道哪导致的超时，其实细心点还会发现maxx每一组数据还得重新赋值，这是第二个问题。。。。

对于双指针有几种模型（自我归纳）那么前后双指针一快一慢往前滑，要么头尾双指针往中间靠，但是对于这道题，举几个例子就知道应该采取前后双指针往前滑，这样就不需要改变指针的位置的，之间一直往前就可以了

这里有个巧思：右指针是否要while找到对应条件后再退出？还是说先往右移，不断累加合适的长度？

其实都可以，大概率不会出现一种超时一种合理的情况，因为核心在于while循环，只不过最后计算的时候一个用 r-l 另一个用 r-l+1，没有太大区别，反正双指针核心在于节奏不同速率不同，推导终止条件即可。

给出AC代码

```c++
#include<bits/stdc++.h>
using namespace std;
int main(){
    int t,n,k;
    int a[300001];
    std::cin>>t;
    while(t--){
        int maxx=0;
        std::cin>>n>>k;
        for(int i=0;i<n;i++) std::cin>>a[i];
        sort(a,a+n);
        int l,r;
        for(l=0,r=0;l<n;l++){
            while(a[r]-a[l]<=k&&r<n){
                maxx=max(maxx,r-l+1);
                r++;
            }
        }
        std::cout<<maxx<<endl;
    }
    return 0;
}
```
