### 分析

它要使相邻；两位异或之后的和最小，你可以想想，如果按照大小排，这样你也不知道两位之间二进制有几位不一样，这样很难做到最终的和最小，而最佳方法就是：让相邻两个数二进制只有一个数不一样，这样结果可以控制在
$$
\sum_{i=0}^{n-1}2^{n-i-1}\times 2^i=\sum_{i=0}^{n-i-1}2^{n-1}=n\times 2^{n-1}
$$

```c++
0
0 1（尝试改变0的倒数1位，得到1，成功）
0 1 3（尝试改变1的倒数1位，得到0，但0在排列中，失败；尝试改变1的倒数第2位，得到3，成功）
0 1 3 2（尝试改变3的倒数1位，得到2，成功）
0 1 3 2 6（尝试改变2的倒数1位，得到3，失败；尝试改变2的倒数第2位，得到0，失败，尝试改变2的倒数
第3位，得到6，成功）
0 1 3 2 6 7 5 4 
实际上这也是格雷码
```

        std::cout<<(i^(i>>1))<<" ";
    }

}

### 分析

可以知道，当（x,y）作为中心位置，辐射出的领域为

<img src="/images/image-20260210155129459.png" alt="image-20260210155129459" style="zoom: 80%;" />

在数组中，要找到最大值，和其所在的位置，然后进行 q 次增援。

每次增员后， 可以对该区域进行类似于如上格子的遍历，将每个点都增加 y 值，增员后的最大值就是 max ( 原最大值 ，相关点增加y之后的最大值）

重复以上步骤，即可实现问题求解。

### 代码

```c++
#include <iostream>
#include <algorithm>
#include<cstring>
#define LL long long
using namespace std;
LL a[1001][1001],b[1001][1001]; 
int n,m,q;
int main() {
    std::cin>>n>>m>>q;
    for(int i=2;i<=n+1;i++)
        for(int j=2;j<=m+1;j++) 
            std::cin>>a[i][j];
    for(int i=2;i<=n+1;i++)
        for(int j=2;j<=m+1;j++) 
            b[i][j] = a[i][j-1]+a[i][j +1]+a[i-1][j-1]+a[i-1][j+1]+a[i+1][j-1]+a[i+1][j+1]+a[i][j-2]+a[i][j+2]+a[i+1][j]+a[i-1][j]+a[i+2][j]+a[i-2][j]+a[i][j];
    LL maxx=-1e9;  
    pair<int,int> idx; 
    for(int i=2;i<=n+1;i++)
        for(int j=2;j<=m+1;j++) 
            if(b[i][j]>maxx) {
                maxx=b[i][j]; 
                idx.first=i;  
                idx.second=j;
            }
    while(q--) 
    {
        int x, y, c;
        std::cin>>x>>y>>c;
        for(int i=-2;i<=2;i++)
            for(int j=-2;j<=2;j++) {
                if(abs(i)+abs(j)>2) continue;
                int xx=x+1+i;
                int yy=y+1+j;
                if(xx>=2&&xx<=n+1&&yy>=2&&yy<=m+1) {
                    b[xx][yy]+=c;
                    if(b[xx][yy] > maxx) {
                        maxx=b[xx][yy];
                        idx.first=xx;
                        idx.second=yy;
                    }
                }
            }
        std::cout<<idx.first-1<<" "<<idx.second-1<<'\n';
    }
    
    return 0;
}
```

E(x)=\frac{205}{216}x \\
S=\sum x_i \\
E=h+\sum E(x_i)=(6-S)+S\cdot \frac{205}{216}=6-S\cdot \frac{11}{216}
$$
