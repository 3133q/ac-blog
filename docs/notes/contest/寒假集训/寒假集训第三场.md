## C

### 题面

<img src="/images/image-20260209000450660.png" alt="image-20260209000450660" style="zoom:80%;" />

> Ps.这道题一开始我看错了，以为非空子序列随便选，想着不是很简单吗，要么0要么1，还好要交的时候发现了题目，所以说题目一定要看习细，提交一定别着急！

### 分析

意思就是给一个字符串，由01组成，然后可以从该字符串中选取非空子序列（并且要求相邻元素不相同），然后将这些非空子序列进行01反转，求出满足最后标准模型所需要的步骤数。

其实很容易，比对一下看看哪里不一样就专门针对这部分进行判断和反转，但这里要注意，一开始我就以为只要根据第一个是1或者0来决定整个字符串最后应该呈现出的样子，但我是错的，因为有可能该字符串就第一个改了，或者因为特殊原因，这样定下来的步骤次数不是最短的，就能发现会![image-20260209001012485](/images/image-20260209001012485.png)

所以说，得两种情况都考虑，最后取最小值。

### 巧思

在拿出所有不合法的字符之后，因为要考虑会出现相邻的字符相同的情况，所以需要用到一种技巧，01互消（

匹配），就是在0出现后，需要对应的1去把它消掉，然后最后看多余的有多少个（0跟1相加），得出答案。对应实现方法看第一个代码

### 代码一

```c++
#include<bits/stdc++.h>
using namespace std;
const int inf=0x3f3f3f3f;
void solve(){
    int n;
    string s;
    std::cin>>n;
    std::cin>>s;
    string t="";
    for(int i=0;i<n;i++){
        if(i%2==0) t+='1';
        else t+='0';
    }
    string a="";
    for(int i=0;i<n;i++){
        if(s[i]!=t[i]) a+=s[i];
    }
    int c0=0,c1=0,ans=inf;
    for(auto e:a){
        if(e=='1'){
            if(c0) c0--;
            c1++;
        }
        else{
            if(c1) c1--;
            c0++;
        }
    }
    ans=min(ans,c0+c1);
    t="";
    a="";
    for(int i=0;i<n;i++){
        if(i%2==0) t+='0';
        else t+='1';
    }
    for(int i=0;i<n;i++){
        if(s[i]!=t[i]) a+=s[i];
    }
    c0=0,c1=0;
    for(auto e:a){
        if(e=='1'){
            if(c0) c0--;
            c1++;
        }
        else{
            if(c1) c1--;
            c0++;
        }
    }
    ans=min(ans,c0+c1);
    std::cout<<ans<<'\n';
    return ;
}
int main(){
    int t;
    std::cin>>t;
    for(int i=0;i<t;i++){
        solve();
    }
    return 0;
}
```

#### 高级的想法

因为这里01匹配也可以转换一下，换为0跟1互去，把0标记为-1,1还是1，这样去求子段和，这里需要求最大子段和和最小子段和，然后绝对值取最大值（因为要保证全部都翻到）

### 代码二

```c++
#include<bits/stdc++.h>
using namespace std;
#define int long long

int f(string s){
    int mx=0,mn=0,now=0;
    for(int i=0;i<(int)s.size();i++){
        if(s[i]=='1')now++;
        else now--;
        if(now<0)now=0;
        mx=max(mx,now);
    }
    now=0;
    for(int i=0;i<(int)s.size();i++){
        if(s[i]=='1')now++;
        else now--;
        if(now>0)now=0;
        mn=min(mn,now);
    }
    return max(mx,abs(mn));
}

void solve(){
    int n,i;
    string s,t;
    cin>>n>>s;
    t="";
    for(i=0;i<n;i++){
        if((i&1)&&s[i]=='1')t+=s[i];
        if(!(i&1)&&s[i]=='0')t+=s[i];
    }
    int ans=f(t);
    t="";
    for(i=0;i<n;i++){
        if((i&1)&&s[i]=='0')t+=s[i];
        if(!(i&1)&&s[i]=='1')t+=s[i];
    }
    ans=min(ans,f(t));
    cout<<ans<<"\n";
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    int _;
    cin>>_;
    while(_--)solve();
    return 0;
}

```

#include<bits/stdc++.h>

## J

### 题面

<img src="/images/image-20260210144546799.png" alt="image-20260210144546799" style="zoom:80%;" />

> 其实这道题可以积累积累，关于二叉树的一个知识。。。

### 思路

一棵有n个点的完全二叉树，根为1，点i的左儿子为2i，右儿子为2i+1，对每个询问给出x，求出与x深度相同的点有多少个，树只有编号1.....n的存在

#### 关键性质

编号的二进制最高位决定深度，设x的最高位是2^d，则x的深度为d，节点编号范围是：
$$
[2^d,2^{d+1}-1]
$$
但由于树只到n，完全二叉树可以不为满，只需要左节点满就行了，实际同层节点为：
$$
[L,R]\quad L=2^d,R=min(n,2^{d+1}-1)
$$
答案直接取区间   R-L+1

### 代码

```c++
#include<bits/stdc++.h>
using namespace std;
void solve(){
    long long n,q,x;
    std::cin>>n>>q;
    auto judge=[&](long long xx)->long long{
        if(xx==1) return 1;
        long long id=2;
        while(xx>((1LL<<id)-1)||xx<(1LL<<(id-1))) id++;
        return min(n,((1LL<<id)-1))-(1LL<<(id-1))+1;
    };
    for(int i=0;i<q;i++){
        std::cin>>x;
        std::cout<<judge(x)<<'\n';
    }
}
int main(){
    int t;
    std::cin>>t;
    for(int i=0;i<t;i++){
        solve();
    }
    return 0;
}
```
