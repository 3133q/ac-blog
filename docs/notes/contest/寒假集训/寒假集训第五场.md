## D

> 合并果子的升级版，唉，卡在了内存超限，AC不了。

### 题面

<img src="/images/image-20260212164815652.png" alt="image-20260212164815652" style="zoom:80%;" />

这道题很明显可以看出同一重量的果子有不止单一数量，与传统的（简单的）合并果子不太一样，可以看看传统的合并果子。

[P1090 [NOIP 2004 提高组\] 合并果子 - 洛谷](https://www.luogu.com.cn/problem/P1090)

会发现这个同一重量就数量为1，所以直接优先队列从小到大不断插，然后自动处理排序，就可以了。

### 难点

在于如何处理多数量的果子，一开始我的想法是输入后直接for循环去把相同重量的所有果子全部插到优先队列里边，这也是最基本的方法，但没招啊，内存超限！！！

<img src="/images/image-20260212165231033.png" alt="image-20260212165231033" style="zoom:80%;" />

> 光荣战绩。。。

### 思路

这道题很巧妙，可以运用pair来处理一对数据（重量和对应的数量），然后利用map去存数据

我们可以知道，相同重量的果子肯定不可能去和比他们大的重量去合并吧，因为他和自己合并不是代价更小吗，要么也只能和比他们更小的重量合并，那么，我们就可以分两半，两个两个去存，然后处理奇数的情况，也就是得和前面一个更小的重量去合并。然后当最后的果子只剩下1时，即可退出！

### 代码

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
const int MOD=1e9+7;
typedef pair<long long,long long>PLL;
void solve(){
    ll n,c,w;
    std::cin>>n;
    map<ll,ll>mp;
    for(ll i=0;i<n;i++){
        std::cin>>c>>w;
        mp[w]+=c;
    }
    priority_queue<PLL,vector<PLL>,greater<PLL>> pq;
    ll tot = 0;
    for(auto [k,v]:mp){
        pq.push({k,v});
        tot+=v;
    }
    ll ans = 0;
    while(tot>1){
        auto [w,c]=pq.top();
        pq.pop();
        ll t=c/2;
        ll r=c%2;
        tot-=t;
        ans=(ans+t*(2*w)%MOD)%MOD;
        if(t>0) pq.push({2*w, t});
        if(r){
            if(pq.size()){
                auto [w2,c2]=pq.top();
                pq.pop();
                c2-=1;
                ans=(ans+w+w2)%MOD;
                pq.push({w+w2,1});
                tot-=1;
                if(c2>0){
                    pq.push({w2,c2});
                }
            }
        }
    }
    std::cout<<ans;
}
int main(){
    solve();
    return 0;
}
```

> Ps.其实类似无限二分，直到把这些数量都处理完成，这样可以避免内存超限。。

### 新颖之处

说的是过程中取模，而不是最后的最大子段和对p取模！！！！

这里运用的方法在于求前缀和的过程中对p取模。

### 分析

这道题很纯粹，就是找到对于p取模的区间和最大的区间，然后输出l，r

当时想着，前缀和去算区间和。但是怎么动态找到区间呢？线段树？但是其实没那么复杂，看完这篇题解，我受益匪浅！！！

### 做法

先使用map记录，分别存着目前最大前缀和，对应的序号，然后动态增大前缀和，为了跳过0的情况，使用upper-bound跳过，然后利用map的键值对特性first，second，去更新最值！！

### 代码

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
ll n,p,x,cnt=0,p0=0,p1=0;
int main(){
	std::cin>>n>>p;
	map<ll,ll> mp;
	mp[0]=0;
	ll sum=0,maxi=-1,l=0,r=0;
	for(int i=1;i<=n;i++){
        std::cin>>x;
		sum=(sum+x)%p;
		auto it=mp.upper_bound(sum);
		if(it==mp.end()) it=mp.begin();
		cnt=it->first;
		p0=it->second;
		p1=(sum-cnt+p)%p;
		if(p1>maxi){
			maxi=p1;
			l=p0;
			r=i-1;
		}
		mp[sum]=i;
	}
	std::cout<<l<<" "<<r<<" "<<maxi<<endl;
	return 0;
}
```
