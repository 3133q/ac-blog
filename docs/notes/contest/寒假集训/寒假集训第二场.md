### 分析

先说说思路吧，表面看来就是如果两个数相等，就可以都离场，然后最后决出一个人就可以了，其实很好想这题只跟最大值有关，因为是存在类问题，但我当时想的是都要考虑，现在我来否决你当时的思想

比如  8 8 7 7 7 6 6

你说8有可能赢吗？绝对没有，因为场上他最大，没有人能淘汰他，除非他自己，他又是偶数个，所以他没有赢的可能。

那么7跟6呢？我当时冒出的想法是：只有当比他大的数全部为偶才行，比如说6，我想着8跟8先走，然后7跟7走，剩下6 6 7，这样不也会输吗？但我没看清楚题面，一个人不止可以比一次😂

比如   8 8 8 7 7 7 6 6

对8分析，他都是奇数了，包赢的啊，对于7,6，即便把两个8先耗走，也无济于事，因为剩下的8一定会将他们淘汰。。。

> 害 是不是发现很简单 当时还卡那么久 真无语。。。

#### 代码

```c++
#include<bits/stdc++.h>
using namespace std;
long long a[200001],v=0,x,maxx=INT_MIN;
int main(){
    map<long long,long long>mp;
    string s;
    long long t,n;
    std::cin>>t;
    for(int i=0;i<t;i++){
        mp.clear();
        s="";
        maxx=INT_MIN;
        std::cin>>n;
        for(int j=0;j<n;j++){
            std::cin>>a[j];
            maxx=max(maxx,a[j]);
        }
        for(int j=0;j<n;j++){
            if(a[j]==maxx) mp[a[j]]++;
        }
        if(mp[maxx]%2==1){
            for(int j=0;j<n;j++){
                if(a[j]==maxx) s+='1';
                else s+='0';
            }
        }
        else{
            for(int j=0;j<n;j++){
                if(a[j]==maxx) s+='0';
                else s+='1';
            }
        }
        std::cout<<s<<'\n';
    }
    return 0;
}
```

## F

考察：数论，位运算

### 题面

![image-20260206162443515](/images/image-20260206162443515.png)

> Ps.当初看到这一题的时候，感觉微死，因为位运算出成这样简直没招（对我来说）

### 分析

> 看完题解，豁然开朗，柳暗花明又一村！

这题其实考构造，所谓构造，就是在不可能中寻求可能！

#### 猜测

$$
x⊕y=gcd(x,y)=n
$$

我们令x是n的倍数，y=x+n，此时可以确保gcd(x,y)=n（不要想说反推会不成立，很正常，构造就是这样无理由地胡乱构造！），那么如何满足x⊕y=n呢？

#### 计算过程

> 可以积累积累哈哈哈

![image-20260206164657357](/images/image-20260206164657357.png)

这个公式背一下就OK了！

得知这个，再由等式可以知道，要使他俩相等，就得让 x&n =0

也就是二进制没有交集，或者后边全是0，也行，这里用到一个很巧妙的思想，直接左移32位（移越多越好，因为这样后边就全部都是0，&过后肯定也是0，满足条件），而且最后的话，直接加个n就是另外一个值，公约数肯定是满足的，同时越大的值加上一个n之后整体变化就很小（即1的出现比较后面），这样就能保证前面大的部分几乎相同，异或后自然最小！

#### 咋构造的呢？

![image-20260206163859500](/images/image-20260206163859500.png)

这不是有样例吗，发现的😎😎

### 代码

## H

### 题面

![image-20260206165326447](/images/image-20260206165326447.png)

> 这题还蛮有趣，给了一段代码要理解，但我当时头脑乱了，没去看。。。。

从这段代码可以得知：权值计算其实就是看看没有重复的数字有多少个，然后1+2+...一直加到个数即可，但这题难就难在要算所有子数组的权值之和！

### 思路

> 这种区间思路可以多想想，多看看，以后才能自己想出来！

我们可以考虑数组中的每个元素对最终答案贡献了多少。

这样考虑，1&lt;=l&lt;=k&lt;=r&lt;=n，如果a[l.....k]中a[i]第一次出现，则产生1的贡献，对于第i个元素，它被统计的条件是：它必须是该范围内a[i]第一次出现，这意味着l必须在x上一次出现的位置pos[x]之后。

#### 合法的条件

$$
l:pos[x]&lt;l\leq i
$$

共有 i-pos[x]中选择
$$
k:i\leq k\leq n\\
r:k\leq r\leq n
$$
对于每一个固定的k，合法的r有n-k+1个

##### 理解方法

固定i，如果r=i，那无疑，贡献为1；如果r=i+1，贡献为2（因为最前面的数可以出现在两个区间）；如果r=i+2，贡献为3 .......... 类推 最后会是n-i+1

##### 公式

$$
\sum _{k=i}^{n}(n-i+1)=1+2+3+...+(n-i+1)=\frac{(n-i+1)(n-i+2)}{2}
$$

最终答案
$$
\sum_{i=1}^{n}(i-pos[a[i]])\times \frac{(n-i+1)(n-i+2)}{2}
$$

### 代码

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
ll n,t,x;
void solve(){
    std::cin>>n;
    ll t=0;
    map<ll,ll>pos;
    auto S=[&](ll x){
        return x*(x+1)/2;
    };
    for(int i=1;i<=n;i++){
        std::cin>>x;
        t+=(i-pos[x])*S(n-i+1);
        pos[x]=i;
    }
    std::cout<<t<<'\n';
}
int main(){
    std::cin>>t;
    for(int i=0;i<t;i++){
        solve();
    }
    return 0;
}
```

### 分析

很好想的这道题，但如果你一味被题目牵着鼻子走，那你肯定想不出来。

他是说是否存在一个起点使他满足回文串，你不要想啥打路径，判断回文数。。。没用的，只要多举几个例子，这种存在类问题很好做的

比如 ：

1 1

0 0

第一个1开始，右边的1就行了，因为回文串最短是2，这样很好满足

0其实也可以，都是2就行了

1 0

0 0

这样的话，1恐怕就不行了，因为我们分析回文串  1001 101 11 010

一定需要找到第二个1或者0，所以得出结论

如果1的数量大于1，即可以找到，否则找不到！

### 代码

```c++
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n,m,t;
	cin>>t;
	while(t--){
		cin>>n>>m;
		vector s(n,string(m,'0'));
		map<char,int> mp;
		for(int i=0;i<n;i++){
			cin>>s[i];
			for (int j=0;j<m;j++) {
				mp[s[i][j]]++;
			}
		}
		for(int i=0;i<n;i++){
			for(int j=0;j<m;j++){
				if(mp[s[i][j]]==1){ 
					cout<<"N";
				}else{
					cout<<"Y";
				}
			}
			cout<<"\n";
		}
	}
	return 0;
}
```
