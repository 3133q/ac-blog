### E

> 这道题挺有意思，用到了神奇的前缀和+变式滑动窗口

#### 题面

<img src="/images/image-20260331232245706.png" alt="image-20260331232245706" style="zoom:80%;" />

#### 分析

可以拿例子来分析

```
20 270 3
1 1 1 5 1 1 1 5 1 1 1 5 1 1 1 5 1 1 1
40 35 50 10 60 55 70 5 80 75 85 10 100 95 110 8 120 115 130 20
```

因为对于采矿次数有限值，所以很自然可以想到这道题得使用滑动窗口，但是很普通的窗口不同之处在于它未必是连续的，而是要在金钱足够的前提下试试能不能挖到最多的矿，所以说要最终得出结果必须动态更新最值

我们可以维护一个优先队列，小根堆去排，自动按照从小到大排序，当窗口到达k-1的长度时，考虑下一个元素的大小，如果比队头大，说明用它肯定价值更大，直接pop掉，然后入队，这里不用担心由于路费导致的最终结果出现问题，因为每次循环都会动态更新一下最值

#### 代码

```c++
#include<iostream>
#include<cstdio>
#include<cstring>
#include<algorithm>
#include<queue>
#include<climits>
#include<cmath>
#define int long long
using namespace std;
const int N=1e5+2;
int c[N],a[N];
signed main(){
	int n,m,k;
	std::cin>>n>>m>>k;
	for(int i=2;i<=n;i++) {
		std::cin>>c[i];
		c[i]=c[i-1]+c[i];
	}
	int ans=0,sum=0;
	for(int i=1;i<=n;i++) std::cin>>a[i];
	priority_queue<int,vector<int>,greater<int>>q;
	for(int i=1;i<=n;i++){
		if(q.size()<k){
			q.push(a[i]);
			sum+=a[i];
		}
		else{
			if(a[i]>q.top()){
				sum-=q.top();
				q.pop();
				q.push(a[i]);
				sum+=a[i];
			}
		}
		sum=min(sum,m-c[i]);
		ans=max(ans,sum);
	}
	std::cout<<ans;
	return 0;
}
```

#### 分析

看完题目应该很容易知道，肯定得贪心的思想去做嘛，因为最大乘客量为W，所以我得保证每次电梯上去的时候满载，这样才能节约时间，但是接下来代码的思路可以好好看看！！！

#### 代码

```c++
#include<iostream>
#include<cstring>
#include<cstdio>
#include<algorithm>
#include<cmath>
#include<climits>
#include<vector>
#define int long long
using namespace std;
const int N=1e6+2;
struct node{
	int a,b;
}f[N];
int v[N],total=0;
bool cmp(node x,node y){
	return x.a<y.a;
}
signed main(){
	int n,x,y,w;
	std::cin>>n>>x>>y>>w;
	for(int i=1;i<=n;i++) std::cin>>f[i].a>>f[i].b;
	sort(f+1,f+1+n,cmp);
	int sum=w,ans=0;
    for(int i=1;i<=n;i++){
        if(sum+f[i].b<=w) {
            sum+=f[i].b;
            continue;
        }
        sum=w-sum;
        f[i].b-=sum;
        sum=f[i].b%w;
        ans+=(f[i].b+w-1)/w*(y-f[i].a)*2;
        if(sum==0) sum=w;
    }
    ans=ans-(y-f[1].a)+abs(x-f[1].a);
	std::cout<<ans;
	return 0;
}
```

> 解释一下，这里的sum可以理解为每层楼经过W个人载走（循环）之后剩下的人数，注意，这里的sum是动态更新的，每当下面楼层的人走之后人数是在变少的，如果小于W则为该层人数的数量，计算的时候看看当前sum+f[i].b是否小于等于w即还可以再往后，就直接累加，随后计算还需要载的人数，（f[i].b+w-1)/w的本质就是向上取整，然后直接加上上下的时间
>
> 同时要注意，因为算的时候默认第一次往返，但起点未必和终点重合，所以说要经过最后一步，值得深思！！！！
