### 2.分析

分析一下其实可以这么想，给定一个长度为k的数组b，定义交替和(alternating sum)为交错正负之和，要找出一个序列中，存在几个i，j，能使ai~aj中的数组满足交替和为0（在mod 1e9+7)条件下

先不直接从数组所有数硬分析，先考虑一下结构
$$
\sum_{i=1}^k(-1)^{i+1}b_i=b1-b2+b3-b4....
$$
如果k为偶数，设它是2m，原式为
$$
b1-b2+b3-b4+b5-b6+....+b_{2m-1}-b_{2m}
$$
化为
$$
(b1-b2)+(b3-b4)+....+(b_{2m-1}-b_{2m})
$$
由于数组是不减序列，因此每一项一定大于等于上一项，所以说
$$
b_{i-1}-b_{i}\leq0
$$
因此，要使整个式子最终结果为0，只能让每一项都为0

总结：如果你想挑偶数个数字，你挑出来的数字必须“成双成对”。也就是说，你想挑数字 2，你要么挑 2个、4个、6个（偶数次），不能挑奇数个。所有数字都必须挑偶数个。



如果k为奇数，假设它是2m+1，原式为
$$
b1-b2+b3-b4+...+b_{2m+1}
$$
化为
$$
b1+(b3-b2)+(b5-b4)+...(b_{2m+1}-b_{2m})
$$
由于是不减序列，所以
$$
b_{i}-b_{i-1}\geq0
$$
所以说，要使原式子结果为0，只能让b1=-1，然后后面那一大串为1

总结：如果你想挑奇数个数字，你挑出来的数字里必须有奇数个-1，有奇数个x，有奇数个 x+1 （比如奇数个 2 和奇数个 3），然后剩下的其他数字全都要挑偶数个（成双成对）。

也就是说，只要我至少有一个-1就行了，我一定能凑出奇数个-1，然后再去找一下有几个x和x+1，这样能凑出一对



上面的分析完了，下面来算一下基础结果，如果全挑偶数个
$$
(_{f}^{0})+(_{f}^{2})+....(_{f}^{2m})
$$
由于
$$
(1+1)^f=
C(f,0) + C(f,1) + C(f,2) + \dots + C(f,f) = 2^f \quad \text{}\\
(1-1)^f=
C(f,0) - C(f,1) + C(f,2) - C(f,3) + \dots = 0 \quad \text{}
\\
\rightarrow\\C(f,0) + C(f,2) + C(f,4) + \dots \quad \text{}=\frac{2^f}{2} = 2^{f-1}\\C(f,1) + C(f,3) + C(f,5) + \dots \quad
=\frac{2^f}{2} = 2^{f-1}
$$
也就是说，对于某一个数字，假设他出现的次数是f，那么选法就是2^f种，将所有数字选法累乘，最终得出式子
$$
2^{n-D}
$$
n为总长度，D为有多少种不同的数字

我们把 
$$
2^{n-D}
$$
 当作一个“基础大礼包”（代码里的变量 P）。

1. **第一种情况（全部成双成对）**：永远是可以凑出来的。贡献 **1个基础大礼包**。
2. **第二种情况（含有 -1，x, x+1）**：只要原数组里同时存在 -1 和某一对相邻的数字 x, x+1，就能凑出来。
   - 如果数组里有 -1，又有 2, 3，就多贡献 1 个基础大礼包。
   - 如果还有 5, 6，就再多贡献 1 个基础大礼包。
   - 我们数一数原数组里有几对这种能接上的相邻正整数（代码里的变量 K）。每有一对，就贡献 1 个基础大礼包。

所以总方案数就是：(1+K)*P            //1就是第一种情况，K 就是第二种情况的种类数



### 3.代码

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int mod=1e9+7;
int fpow(int a,int n){
	int base=1LL;
	while(n){
		if(n&1) base=base*a%mod;
		n>>=1;
		a=a*a%mod;
	}
	return base%mod;
}
void solve() {
    int n;
    std::cin>>n;
    bool has_minus_1=false; 
    int D=0;                
    int K=0;               
    int last_val=-3;      
    for(int i=0;i<n;++i) {
        int val;
        std::cin>>val;
        if(val==-1) has_minus_1=true;
        if(val!=last_val) {
            D++; 
            if(has_minus_1&&last_val>0&&val==last_val+1) K++; 
            last_val=val; 
        }
    }
    int P=fpow(2,n-D);
    int ans=(P*(K+1))%mod;
    ans=(ans+mod)%mod;
    std::cout<<ans<<"\n";
}
signed main(){
	int t;
	std::cin>>t;
	for(int i=0;i<t;i++) solve();
	return 0;
}
```
